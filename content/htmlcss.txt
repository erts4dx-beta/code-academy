=== 입문 | html-basics | HTML 문서의 기본 구조
HTML(HyperText Markup Language)은 웹 페이지의 **구조와 의미**를 정의합니다. `<태그>` 로 내용을 감싸 "이것은 제목", "이것은 문단"이라고 브라우저에 알려 줍니다.

## 기본 개념
- **요소(element)**: 여는 태그 + 내용 + 닫는 태그. 예: `<p>문단</p>`
- **빈 요소**: 닫는 태그가 없음. 예: `<img>`, `<br>`, `<input>`, `<meta>`
- **속성(attribute)**: 태그에 추가 정보. 예: `<a href="https://...">`
- 요소는 **중첩**할 수 있으며, 올바른 순서로 닫아야 합니다.

## 문서 골격
`<!DOCTYPE html>` 선언 → `<html lang="ko">` → `<head>`(메타 정보: 문자 인코딩, 제목, CSS 연결) + `<body>`(화면에 보이는 내용).

> `<meta charset="utf-8">` 이 없으면 한글이 깨질 수 있습니다. `viewport` 메타 태그는 모바일 반응형의 필수 요소입니다.

메모장이나 VS Code로 `index.html` 을 저장하고 더블클릭하면 브라우저에서 바로 볼 수 있습니다.
--- code
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>나의 첫 웹 페이지</title>
</head>
<body>
  <h1>안녕하세요!</h1>
  <h2>자기소개</h2>
  <p>저는 <strong>웹 개발</strong>을 배우고 있습니다.</p>
  <p>줄을<br>바꿀 수 있어요.</p>
  <!-- 주석: 화면에 표시되지 않습니다 -->
  <hr>
  <a href="https://developer.mozilla.org/ko/" target="_blank">MDN 문서 보기</a>
  <img src="photo.jpg" alt="프로필 사진" width="200">
</body>
</html>
--- exercise
자신을 소개하는 HTML 문서를 만들어 보세요. `<h1>` 제목, 두 개의 `<p>` 문단(하나에는 `<em>` 강조 포함), 좋아하는 사이트로 가는 링크 하나를 넣고, 올바른 문서 골격(DOCTYPE, head, meta charset, title)을 갖추세요.
--- solution

=== 입문 | html-content | 텍스트, 목록, 표, 링크
## 텍스트 요소
- 제목: `<h1>` ~ `<h6>` (한 페이지에 `<h1>` 은 보통 하나, 단계를 건너뛰지 않기)
- `<p>` 문단, `<strong>` 중요(굵게), `<em>` 강조(기울임), `<code>` 코드, `<blockquote>` 인용

## 목록
- `<ul>` 순서 없는 목록, `<ol>` 순서 있는 목록, 각 항목은 `<li>`
- 목록은 중첩할 수 있습니다.

## 표
`<table>` 안에 `<thead>`, `<tbody>`, 행 `<tr>`, 제목 셀 `<th>`, 데이터 셀 `<td>`. `colspan`, `rowspan` 으로 셀을 병합합니다. 표는 **표 형식 데이터에만** 사용하고 레이아웃용으로 쓰지 마세요.

## 링크

=== 입문 | css-basics | CSS 기초: 선택자와 속성
CSS(Cascading Style Sheets)는 HTML 요소의 **모양**을 정합니다. `선택자 { 속성: 값; }` 형태의 규칙으로 작성합니다.

## 적용 방법
1. 외부 파일(권장): `<link rel="stylesheet" href="style.css">`
2. `<style>` 태그: head 안에 작성
3. 인라인: `<p style="color: red">` (유지보수가 어려워 지양)

## 주요 선택자
- 태그: `p`, 클래스: `.card`, 아이디: `#header`
- 자손: `nav a`, 자식: `ul > li`, 여러 개: `h1, h2`
- 속성: `input[type="email"]`
- 가상 클래스: `a:hover`, `li:first-child`, `:nth-child(2n)`, `:focus`
- 가상 요소: `::before`, `::after`, `::placeholder`

## 우선순위(명시도)와 캐스케이드
여러 규칙이 충돌하면 **인라인 > 아이디 > 클래스/속성/가상 클래스 > 태그** 순으로 이기고, 명시도가 같으면 **나중에 작성된 규칙**이 적용됩니다. `!important` 는 최후의 수단입니다.
--- code css
/* style.css */
body {
  font-family: "Noto Sans KR", sans-serif;
  color: #222;
  background-color: #fafafa;
  line-height: 1.6;
}

h1 {
  color: #4f46e5;
  font-size: 2rem;
}

.card {
  background: white;
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  padding: 16px;
}

#main-title { text-transform: uppercase; }

nav a { text-decoration: none; color: #555; }
nav a:hover { color: #4f46e5; text-decoration: underline; }

li:nth-child(odd) { background: #f3f4f6; }

input[type="email"]:focus {
  outline: 2px solid #4f46e5;
}

.note::before {
  content: "📌 ";
}
--- exercise

=== 초급 | box-model | 박스 모델과 단위
모든 HTML 요소는 사각형 **박스**입니다. 안쪽부터 `content`(내용) → `padding`(안쪽 여백) → `border`(테두리) → `margin`(바깥 여백) 순서로 감쌉니다.

## box-sizing
기본값 `content-box` 에서는 `width` 가 내용 영역만의 너비라서, padding과 border를 더하면 실제 크기가 커집니다. `box-sizing: border-box` 로 설정하면 width에 padding과 border가 포함되어 계산이 직관적입니다. 대부분의 프로젝트는 전역으로 적용합니다.

## display
- `block`: 한 줄 전체 차지, width/height 지정 가능 (`div`, `p`, `h1`)
- `inline`: 내용만큼만 차지, width/height 무시 (`span`, `a`, `strong`)
- `inline-block`: 인라인처럼 배치되지만 크기 지정 가능
- `none`: 화면에서 제거

## 단위
- `px`: 고정 크기
- `rem`: 루트(html) 글자 크기 기준 — 글꼴 크기에 권장
- `em`: 부모(자신) 글자 크기 기준
- `%`: 부모 기준 비율, `vw`/`vh`: 화면 너비/높이의 1%

> 세로 방향으로 붙은 두 블록의 margin은 더해지지 않고 큰 쪽 하나만 적용됩니다(**마진 상쇄**).
--- code css
*, *::before, *::after {
  box-sizing: border-box;   /* 전역 권장 설정 */
}

html { font-size: 16px; }   /* 1rem = 16px */

.box {
  width: 300px;              /* border-box라 전체 너비가 정확히 300px */
  padding: 20px;             /* 상하좌우 */
  border: 4px solid #4f46e5;
  margin: 16px auto;         /* 상하 16px, 좌우 auto = 가운데 정렬 */
}

.spacing {
  padding: 10px 20px;        /* 상하 10, 좌우 20 */
  margin: 0 0 1.5rem;        /* 상 0, 좌우 0, 하 1.5rem */
}

.title { font-size: 1.5rem; }        /* 24px */
.title small { font-size: 0.75em; }  /* 부모(24px)의 0.75 = 18px */

.hero { height: 60vh; }

.badge {
  display: inline-block;     /* 인라인 배치 + 크기 지정 */
  padding: 2px 8px;
  border-radius: 999px;
  background: #eef2ff;
}
--- exercise
`content-box` 상태에서 `width: 200px; padding: 10px; border: 5px solid;` 인 요소의 실제 화면 너비는 얼마일까요? 그리고 같은 요소를 `border-box` 로 바꾸면 내용 영역 너비는 얼마가 되는지 계산하고, CSS로 확인할 수 있는 코드를 작성하세요.
--- solution css
/* content-box: 200 + 10*2 + 5*2 = 230px
   border-box : 전체 200px, 내용 영역 = 200 - 20 - 10 = 170px */
.a, .b {
  width: 200px;
  padding: 10px;
  border: 5px solid tomato;
  margin-bottom: 8px;
}
.a { box-sizing: content-box; }  /* 개발자 도구로 보면 230px */
.b { box-sizing: border-box; }   /* 200px */

=== 초급 | flexbox | Flexbox 레이아웃
**Flexbox** 는 요소를 **한 방향(가로 또는 세로)** 으로 배치하는 레이아웃 방식입니다. 부모에 `display: flex` 를 주면 자식들이 flex 아이템이 됩니다.

## 컨테이너(부모) 속성
- `flex-direction`: `row`(기본, 가로) / `column`(세로)
- `justify-content`: **주축** 정렬 — `flex-start`, `center`, `space-between`, `space-around`, `space-evenly`
- `align-items`: **교차축** 정렬 — `stretch`(기본), `center`, `flex-start`, `flex-end`
- `flex-wrap: wrap`: 공간이 부족하면 줄바꿈
- `gap`: 아이템 사이 간격

## 아이템(자식) 속성
- `flex: 1`: 남는 공간을 비율대로 차지 (`flex-grow`, `flex-shrink`, `flex-basis` 단축)
- `align-self`: 개별 교차축 정렬
- `order`: 표시 순서 변경

> 요소를 화면 정중앙에 두는 가장 쉬운 방법: 부모에 `display: flex; justify-content: center; align-items: center;`
--- code
<style>
  .navbar {
    display: flex;
    justify-content: space-between;  /* 로고는 왼쪽, 메뉴는 오른쪽 */
    align-items: center;
    padding: 12px 24px;
    background: #111827;
    color: white;
  }
  .menu { display: flex; gap: 16px; list-style: none; margin: 0; padding: 0; }

  .center {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 200px;
    border: 2px dashed #ccc;
  }

  .layout { display: flex; gap: 16px; }
  .sidebar { flex: 0 0 200px; }      /* 고정 200px */
  .content { flex: 1; }              /* 나머지 전부 */

  .cards { display: flex; flex-wrap: wrap; gap: 12px; }
  .cards > div { flex: 1 1 200px; padding: 16px; background: #eef2ff; }
</style>

<nav class="navbar">
  <strong>LOGO</strong>
  <ul class="menu"><li>홈</li><li>소개</li><li>문의</li></ul>
</nav>
<div class="center">정중앙!</div>
<div class="layout">
  <aside class="sidebar">사이드바</aside>
  <main class="content">본문</main>
</div>
<div class="cards"><div>카드1</div><div>카드2</div><div>카드3</div></div>
--- exercise
푸터를 만들어 보세요. 왼쪽에는 저작권 문구, 가운데에는 링크 3개, 오른쪽에는 SNS 아이콘 텍스트가 오도록 Flexbox로 배치하고, 화면이 좁으면 세로로 쌓이도록 `flex-wrap` 과 `gap` 을 활용하세요.

=== 초급 | forms | 폼과 시맨틱 HTML
## 폼(form)
사용자 입력을 받는 요소입니다.
- `<input type="...">`: `text`, `email`, `password`, `number`, `date`, `checkbox`, `radio`, `file` 등
- `<label for="id">`: 입력 요소와 연결 — 클릭 영역이 넓어지고 스크린 리더가 읽어 줌
- `<select>`, `<textarea>`, `<button type="submit">`
- 기본 검증 속성: `required`, `minlength`, `maxlength`, `min`, `max`, `pattern`

=== 중급 | grid | CSS Grid 레이아웃
**Grid** 는 행과 열의 **2차원** 레이아웃 시스템입니다. Flexbox가 한 줄 정렬에 강하다면, Grid는 전체 페이지 구조나 카드 격자에 강합니다.

## 주요 속성
- `grid-template-columns: 200px 1fr 1fr` — 열 크기 정의. `fr` 은 남은 공간의 비율
- `repeat(3, 1fr)` — 반복
- `repeat(auto-fill, minmax(220px, 1fr))` — **미디어 쿼리 없이** 화면 크기에 따라 열 개수 자동 조절
- `gap` — 셀 간격
- `grid-column: 1 / 3` 또는 `span 2` — 여러 칸 차지
- `grid-template-areas` — 영역 이름으로 레이아웃을 그림처럼 정의

## Flexbox vs Grid
- 한 방향 나열(메뉴, 버튼 그룹) → Flexbox
- 행과 열이 모두 중요한 구조(페이지 골격, 갤러리) → Grid
- 둘을 섞어 쓰는 것이 일반적입니다.
--- code
<style>
  .page {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
      "header header"
      "sidebar main"
      "footer footer";
    min-height: 100vh;
    gap: 12px;
  }
  .page > header { grid-area: header; background: #c7d2fe; }
  .page > aside  { grid-area: sidebar; background: #e0e7ff; }
  .page > main   { grid-area: main; }
  .page > footer { grid-area: footer; background: #c7d2fe; }

  .gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
    gap: 16px;
  }
  .gallery .featured {
    grid-column: span 2;    /* 두 칸 차지 */
    grid-row: span 2;
  }
  .gallery div { background: #eef2ff; padding: 24px; border-radius: 8px; }
</style>

<div class="page">
  <header>헤더</header>
  <aside>사이드바</aside>
  <main>
    <div class="gallery">
      <div class="featured">추천</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div>
    </div>
  </main>
  <footer>푸터</footer>
</div>

=== 중급 | responsive | 반응형 디자인과 미디어 쿼리
**반응형 웹**은 하나의 HTML로 휴대폰, 태블릿, 데스크톱 등 모든 화면에 맞게 레이아웃을 바꾸는 방식입니다.

## 핵심 도구
- `viewport` 메타 태그 (필수)
- **미디어 쿼리**: `@media (min-width: 768px) { ... }` — 조건을 만족할 때만 규칙 적용
- 유연한 단위: `%`, `fr`, `rem`, `vw`, `clamp()`
- 유연한 이미지: `img { max-width: 100%; height: auto; }`

## 모바일 우선(Mobile First)
기본 스타일을 작은 화면 기준으로 작성하고, `min-width` 미디어 쿼리로 큰 화면 스타일을 **추가**하는 방식입니다. CSS가 단순해지고 모바일 성능에 유리합니다.

## 유용한 기능
- `clamp(최소, 선호, 최대)`: `font-size: clamp(1.5rem, 4vw, 3rem)` — 화면에 따라 부드럽게 변하는 글자 크기
- `@media (prefers-color-scheme: dark)`: 시스템 다크 모드 감지
- `@media (prefers-reduced-motion: reduce)`: 애니메이션 줄이기 설정 존중
--- code css
/* 모바일 우선: 기본은 1열 */
.container {
  padding: 16px;
}
.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}
img {
  max-width: 100%;
  height: auto;
}
h1 {
  font-size: clamp(1.75rem, 5vw, 3rem);
}
.menu { display: none; }        /* 모바일에서는 햄버거 메뉴 사용 */

/* 태블릿 이상 */
@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}

/* 데스크톱 이상 */
@media (min-width: 1024px) {
  .container { max-width: 1100px; margin: 0 auto; }
  .grid { grid-template-columns: repeat(3, 1fr); }
  .menu { display: flex; }
  .hamburger { display: none; }
}

/* 사용자 환경 설정 존중 */
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #eee; }
}
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
--- exercise
모바일 우선 방식으로, 기본은 상품 카드 1열, 600px 이상에서 2열, 900px 이상에서 4열이 되도록 CSS를 작성하세요. 제목 글자 크기는 `clamp()` 로 1.5rem~2.5rem 사이에서 변하게 하세요.
--- solution css

  display: grid;
  grid-template-columns: 1fr;
  gap: 12px;
}
@media (min-width: 600px) {
  .products { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 900px) {
  .products { grid-template-columns: repeat(4, 1fr); }
}
.products h2 {
  font-size: clamp(1.5rem, 3vw, 2.5rem);
}

=== 중급 | position | 포지셔닝, z-index, 변수
## position 속성
- `static`: 기본값, 문서 흐름대로
- `relative`: 원래 자리를 기준으로 이동. 자식 `absolute` 의 기준점 역할
- `absolute`: 문서 흐름에서 빠지고, 가장 가까운 **position이 지정된 조상** 기준으로 배치
- `fixed`: 화면(뷰포트) 기준 고정 — 플로팅 버튼
- `sticky`: 스크롤하다가 지정 위치에 닿으면 고정 — 상단 헤더, 표 머리글

`top`, `right`, `bottom`, `left` 로 위치를, `z-index` 로 겹침 순서를 정합니다(position이 static이 아닐 때 동작).

## CSS 변수 (사용자 정의 속성)
`--main-color: #4f46e5;` 로 선언하고 `var(--main-color)` 로 사용합니다. 하위 요소로 **상속**되고 자바스크립트로 실시간 변경이 가능해 **테마(다크 모드)** 구현에 최적입니다. 이 사이트의 다크 모드도 CSS 변수로 만들어졌습니다.

=== 고급 | animation | 트랜지션과 애니메이션
## transition
속성 값이 바뀔 때 **부드럽게 변화**시킵니다: `transition: 속성 시간 타이밍함수 지연;`
예: `transition: transform 0.2s ease-out;`

## transform
요소를 이동(`translate`), 회전(`rotate`), 확대(`scale`), 기울임(`skew`)합니다. 레이아웃을 다시 계산하지 않아 성능이 좋습니다.

## @keyframes 애니메이션
여러 단계의 애니메이션을 정의하고 `animation` 속성으로 적용합니다: 이름, 시간, 반복 횟수(`infinite`), 방향(`alternate`) 등.

## 성능 팁
- `transform` 과 `opacity` 만 애니메이션하면 GPU 합성으로 부드럽습니다.
- `width`, `top`, `margin` 등을 애니메이션하면 매 프레임 레이아웃 계산이 발생해 버벅일 수 있습니다.
- 접근성: `prefers-reduced-motion` 설정을 존중하세요.
--- code
<style>
  .btn {
    padding: 12px 24px;
    background: #4f46e5;
    color: white;
    border: none;
    border-radius: 10px;
    transition: transform 0.15s ease, box-shadow 0.15s ease;
  }
  .btn:hover {
    transform: translateY(-3px);
    box-shadow: 0 8px 20px rgba(79, 70, 229, 0.4);
  }
  .btn:active { transform: scale(0.97); }

  @keyframes spin {
    to { transform: rotate(360deg); }
  }
  .spinner {
    width: 40px; height: 40px;
    border: 4px solid #e5e7eb;
    border-top-color: #4f46e5;
    border-radius: 50%;
    animation: spin 0.8s linear infinite;
  }

  @keyframes fadeUp {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
  }
  .card { animation: fadeUp 0.5s ease-out both; }
  .card:nth-child(2) { animation-delay: 0.1s; }
  .card:nth-child(3) { animation-delay: 0.2s; }

  @media (prefers-reduced-motion: reduce) {
    .spinner, .card { animation: none; }
  }
</style>
<button class="btn">마우스를 올려 보세요</button>

=== 고급 | accessibility | 접근성과 웹 표준 실전
**웹 접근성(a11y)** 은 장애가 있는 사용자를 포함해 누구나 웹을 이용할 수 있게 하는 것입니다. 한국에서도 공공기관 등은 웹 접근성 준수가 법적 의무이며, 접근성이 좋은 사이트는 SEO와 사용성도 좋습니다.

## 핵심 체크리스트
- 모든 의미 있는 이미지에 `alt`, 장식 이미지는 `alt=""`
- 시맨틱 태그와 올바른 제목 계층(h1 → h2 → h3)
- 모든 폼 요소에 `<label>`
- **키보드만으로** 모든 기능 사용 가능 (Tab 이동, Enter/Space 실행), `:focus-visible` 스타일 제공
- 글자와 배경의 **명도 대비** 4.5:1 이상 (큰 글자 3:1)
- 색상만으로 정보를 전달하지 않기 (오류를 빨간색 + 아이콘/문구로)
- `<html lang="ko">` 로 언어 지정

## ARIA
네이티브 HTML로 표현할 수 없을 때만 `role`, `aria-label`, `aria-expanded`, `aria-live` 등을 사용합니다. **"ARIA를 쓰지 않는 것이 최선의 ARIA"** 라는 말처럼, `<button>` 같은 네이티브 요소를 먼저 고려하세요.
--- code
<a class="skip-link" href="#main">본문 바로가기</a>

<header>
  <nav aria-label="주 메뉴">
    <button aria-expanded="false" aria-controls="menu" id="menuBtn">메뉴</button>
    <ul id="menu" hidden>
      <li><a href="/" aria-current="page">홈</a></li>
      <li><a href="/courses">강의</a></li>
    </ul>
  </nav>
</header>

<main id="main">
  <h1>강의 목록</h1>
  <img src="chart.png" alt="2026년 월별 수강생 수: 1월 120명에서 9월 480명으로 증가">
  <img src="divider.png" alt="">

  <form>
    <label for="q">강의 검색</label>
    <input id="q" type="search" aria-describedby="q-help">
    <p id="q-help">언어 이름이나 주제로 검색하세요.</p>
    <p role="alert" class="error">⚠️ 검색어를 입력해 주세요.</p>
  </form>
  <div aria-live="polite" id="status"></div>
</main>

<style>
  .skip-link { position: absolute; left: -9999px; }
  .skip-link:focus { left: 8px; top: 8px; background: #fff; padding: 8px; }
  :focus-visible { outline: 3px solid #4f46e5; outline-offset: 2px; }
</style>
<script>
  const btn = document.getElementById("menuBtn");
  btn.addEventListener("click", () => {
    const open = btn.getAttribute("aria-expanded") === "true";
    btn.setAttribute("aria-expanded", String(!open));
    document.getElementById("menu").hidden = open;
  });
</script>
--- exercise
다음 코드의 접근성 문제를 찾아 고쳐 보세요: `<div onclick="save()" style="color:#aaa;background:#fff">저장</div>` 과 `<img src="logo.png">`, `<input placeholder="이메일">`.
--- solution
<!-- 1) div 대신 키보드 접근 가능한 button, 충분한 명도 대비 -->
<button type="button" onclick="save()" style="color:#1f2937;background:#fff">저장</button>

<!-- 2) 이미지 대체 텍스트 -->
<img src="logo.png" alt="코드 아카데미 로고">

<!-- 3) placeholder는 label을 대신할 수 없음 -->
<label for="email">이메일</label>
<input id="email" type="email" placeholder="you@example.com">
