=== 입문 | hello | 자바 시작하기: JDK와 Hello World
자바 코드는 `javac` 컴파일러가 **바이트코드(.class)** 로 변환하고, **JVM(자바 가상 머신)** 이 이를 실행합니다. JVM만 있으면 운영체제와 관계없이 같은 프로그램이 동작합니다.

## 준비
- JDK(Java Development Kit) 설치: Eclipse Temurin, Oracle JDK 등 (LTS 버전인 21 또는 25 권장)
- `javac Hello.java` → `java Hello` 로 컴파일 후 실행
- Java 11+ 에서는 `java Hello.java` 로 단일 파일을 바로 실행할 수 있습니다.
- IDE: IntelliJ IDEA(가장 인기), Eclipse, VS Code

## 기본 규칙
- 모든 코드는 **클래스 안에** 작성합니다. `public class` 이름과 파일 이름이 같아야 합니다.
- 프로그램은 `public static void main(String[] args)` 메서드에서 시작합니다.
- 문장 끝에 세미콜론(`;`)이 필수이고, 대소문자를 구분합니다.
--- code
// 파일 이름: Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
        System.out.println("안녕하세요, 자바!");
        System.out.print("줄바꿈 없이 ");
        System.out.println("출력");
        System.out.printf("%s는 %d년에 등장했습니다.%n", "Java", 1995);
    }
}

=== 입문 | types | 변수와 자료형
자바는 **정적 타입 언어**로, 변수를 선언할 때 타입을 정해야 하고 다른 타입의 값을 넣을 수 없습니다.

## 기본형(primitive) 8가지
- 정수: `byte`(1B), `short`(2B), `int`(4B, 기본), `long`(8B, 숫자 뒤 `L`)
- 실수: `float`(4B, 뒤에 `f`), `double`(8B, 기본)
- `char`: 문자 하나, 작은따옴표 `'A'`
- `boolean`: `true` / `false`

## 참조형
`String`, 배열, 클래스 객체 등. 변수에는 객체의 **주소(참조)** 가 저장됩니다.

## 형 변환
- 작은 타입 → 큰 타입: 자동 (`int` → `long` → `double`)
- 큰 타입 → 작은 타입: 명시적 캐스팅 `(int) 3.9` → `3` (소수점 버림)
- 문자열 ↔ 숫자: `Integer.parseInt("42")`, `String.valueOf(42)`

> Java 10+ 에서는 지역 변수에 `var` 를 써서 타입 추론을 할 수 있습니다: `var list = new ArrayList<String>();`
--- code
public class Types {
    public static void main(String[] args) {
        int age = 30;
        long population = 51_700_000L;
        double pi = 3.14159;
        char grade = 'A';
        boolean isJavaFun = true;
        String name = "길동";

        System.out.println(name + " " + age + " " + grade + " " + isJavaFun);

        int a = 7, b = 2;
        System.out.println(a / b);          // 3 (정수 나눗셈)
        System.out.println(a % b);          // 1
        System.out.println((double) a / b); // 3.5

        double d = 9.99;
        int i = (int) d;                    // 9
        int parsed = Integer.parseInt("123");
        var text = "var로 추론된 String";

        System.out.println(i + parsed);     // 132
        System.out.println(Integer.MAX_VALUE + 1);  // -2147483648 (오버플로!)
        System.out.println(text.length());
    }
}

=== 입문 | strings-io | 문자열과 입력 받기
## String
- 문자열은 **불변 객체**입니다. 메서드는 새 문자열을 반환합니다.
- 주요 메서드: `length()`, `charAt(i)`, `substring(a, b)`, `indexOf`, `contains`, `toUpperCase`, `trim`/`strip`, `split`, `replace`, `isEmpty`/`isBlank`
- **비교는 반드시 `equals()`** 를 사용하세요. `==` 는 같은 객체인지(주소)를 비교합니다.
- 반복해서 이어 붙일 때는 `StringBuilder` 가 효율적입니다.
- Java 15+ 텍스트 블록: `"""` 로 여러 줄 문자열

## 입력 받기
`Scanner` 클래스로 키보드 입력을 받습니다: `nextInt()`, `nextDouble()`, `nextLine()`, `next()`.
--- code
import java.util.Scanner;

public class Strings {
    public static void main(String[] args) {
        String s = "Hello, Java";
        System.out.println(s.length());          // 11
        System.out.println(s.charAt(0));         // H
        System.out.println(s.substring(7));      // Java
        System.out.println(s.toUpperCase());
        System.out.println(s.contains("Java"));  // true
        System.out.println(String.join("-", "2026", "10", "05"));

        String a = new String("hi");
        String b = "hi";
        System.out.println(a == b);              // false (다른 객체)
        System.out.println(a.equals(b));         // true  (내용 비교)

        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) sb.append(i).append(i < 5 ? "," : "");
        System.out.println(sb);                  // 1,2,3,4,5

        String json = """
            {"name": "길동"}
            """;
        System.out.print(json);

        Scanner sc = new Scanner(System.in);
        System.out.print("이름을 입력하세요: ");
        String name = sc.nextLine();
        System.out.println("반가워요, " + name + "님!");
    }
}

public class Capitalize {
    public static void main(String[] args) {
        String[] words = "apple,banana,cherry".split(",");
        StringBuilder sb = new StringBuilder();
        for (String w : words) {
            if (sb.length() > 0) sb.append(" ");
            sb.append(Character.toUpperCase(w.charAt(0))).append(w.substring(1));
        }
        System.out.println(sb);   // Apple Banana Cherry
    }
}

--- code
public class Control {
    public static void main(String[] args) {
        int score = 85;
        String grade;
        if (score >= 90) grade = "A";
        else if (score >= 80) grade = "B";
        else grade = "C";
        System.out.println(grade);

        String day = "SAT";
        String type = switch (day) {
            case "SAT", "SUN" -> "주말";
            case "MON", "TUE", "WED", "THU", "FRI" -> "평일";
            default -> "알 수 없음";
        };
        System.out.println(type);

        for (int i = 2; i <= 9; i += 7) {
            for (int j = 1; j <= 3; j++) {
                System.out.print(i + "x" + j + "=" + (i * j) + " ");
            }
            System.out.println();
        }

        int[] nums = {3, 8, 1, 9};
        int max = Integer.MIN_VALUE;
        for (int n : nums) if (n > max) max = n;
        System.out.println("최댓값: " + max);

        outer:
        for (int i = 0; i < 5; i++) {
            for (int j = 0; j < 5; j++) {
                if (i * j == 6) {
                    System.out.println("찾음: " + i + ", " + j);
                    break outer;
                }
            }
        }
    }
}

1부터 100 사이의 소수(prime)를 모두 출력하고 개수를 세는 프로그램을 작성하세요.
--- solution
public class Primes {
    public static void main(String[] args) {
        int count = 0;
        for (int n = 2; n <= 100; n++) {
            boolean prime = true;
            for (int d = 2; d * d <= n; d++) {
                if (n % d == 0) { prime = false; break; }
            }
            if (prime) { System.out.print(n + " "); count++; }
        }
        System.out.println("\n개수: " + count);   // 25
    }
}

=== 초급 | arrays-methods | 배열과 메서드
## 배열
같은 타입 값을 고정 길이로 저장합니다. `int[] a = new int[5];` (기본값 0으로 채워짐) 또는 `int[] a = {1, 2, 3};`. 길이는 `a.length`. 범위를 벗어나면 `ArrayIndexOutOfBoundsException`.
- `Arrays.toString(a)`, `Arrays.sort(a)`, `Arrays.fill`, `Arrays.copyOf`
- 2차원 배열: `int[][] grid = new int[3][4];`

## 메서드
`접근제어자 static 반환타입 이름(매개변수)` 형식입니다.
- **오버로딩**: 이름이 같고 매개변수 목록이 다른 메서드를 여러 개 정의
- 가변 인자: `int sum(int... nums)`
- 자바는 항상 **값에 의한 전달(pass by value)** 입니다. 객체를 넘기면 참조 값이 복사되므로, 메서드 안에서 객체 내용을 바꾸면 원본에 반영됩니다.
--- code
import java.util.Arrays;

public class ArraysMethods {
    static int sum(int... nums) {
        int total = 0;
        for (int n : nums) total += n;
        return total;
    }

    static double average(int[] arr) {
        return arr.length == 0 ? 0 : (double) sum(arr) / arr.length;
    }

    // 오버로딩
    static String describe(int x) { return "정수 " + x; }
    static String describe(String s) { return "문자열 " + s; }

    static void doubleAll(int[] arr) {
        for (int i = 0; i < arr.length; i++) arr[i] *= 2;   // 원본 배열이 바뀜
    }

    public static void main(String[] args) {
        int[] scores = {88, 72, 95, 60};
        Arrays.sort(scores);
        System.out.println(Arrays.toString(scores));      // [60, 72, 88, 95]
        System.out.println(sum(1, 2, 3) + ", " + average(scores));

        System.out.println(describe(7) + " / " + describe("seven"));

        doubleAll(scores);
        System.out.println(Arrays.toString(scores));      // [120, 144, 176, 190]

        int[][] grid = new int[3][3];
        for (int r = 0; r < 3; r++)
            for (int c = 0; c < 3; c++)
                grid[r][c] = r * 3 + c;
        System.out.println(Arrays.deepToString(grid));
    }
}
--- exercise
정수 배열을 받아 뒤집은 **새 배열**을 반환하는 `static int[] reverse(int[] arr)` 와, 배열에서 특정 값의 인덱스를 찾아 반환(없으면 -1)하는 `static int indexOf(int[] arr, int target)` 을 작성하세요.
--- solution
import java.util.Arrays;

public class ArrayUtil {
    static int[] reverse(int[] arr) {
        int[] result = new int[arr.length];
        for (int i = 0; i < arr.length; i++) result[i] = arr[arr.length - 1 - i];
        return result;
    }

    static int indexOf(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) if (arr[i] == target) return i;
        return -1;
    }

    public static void main(String[] args) {
        int[] a = {1, 2, 3, 4};
        System.out.println(Arrays.toString(reverse(a)));   // [4, 3, 2, 1]
        System.out.println(indexOf(a, 3) + " " + indexOf(a, 9));  // 2 -1
    }
}

=== 초급 | oop | 클래스와 객체
## 클래스의 구성
- **필드**: 객체의 상태 (보통 `private`)
- **생성자**: `new` 로 객체를 만들 때 호출. 클래스 이름과 같고 반환 타입 없음
- **메서드**: 객체의 동작
- `this`: 현재 객체 자신

## 캡슐화
필드를 `private` 으로 숨기고 `public` getter/setter 메서드로만 접근하게 하면, 잘못된 값이 들어오는 것을 막을 수 있습니다.

## static
`static` 멤버는 객체가 아닌 **클래스에 속하며** 모든 객체가 공유합니다. 예: 생성된 객체 수 카운트, `Math.max()` 같은 유틸리티.

## record (Java 16+)
불변 데이터 클래스를 한 줄로: `record Point(int x, int y) {}` — 생성자, getter(`x()`), `equals`, `hashCode`, `toString` 자동 생성.
--- code
public class OopDemo {
    static class Account {
        private static int count = 0;
        private final String owner;
        private long balance;

        Account(String owner, long initial) {
            this.owner = owner;
            this.balance = initial;
            count++;
        }

        Account(String owner) {
            this(owner, 0);          // 다른 생성자 호출
        }

        void deposit(long amount) {
            if (amount <= 0) throw new IllegalArgumentException("입금액은 양수여야 합니다");
            balance += amount;
        }

        boolean withdraw(long amount) {
            if (amount > balance) return false;
            balance -= amount;
            return true;
        }

        long getBalance() { return balance; }
        String getOwner() { return owner; }
        static int getCount() { return count; }

        @Override
        public String toString() {
            return owner + "님 잔액 " + String.format("%,d", balance) + "원";
        }
    }

    record Point(int x, int y) {
        double distance() { return Math.sqrt(x * x + y * y); }
    }

    public static void main(String[] args) {
        Account a = new Account("길동", 10_000);
        Account b = new Account("영희");
        a.deposit(5_000);
        System.out.println(a.withdraw(20_000));   // false
        System.out.println(a);                    // 길동님 잔액 15,000원
        System.out.println(Account.getCount());   // 2

        Point p = new Point(3, 4);
        System.out.println(p + " " + p.distance() + " " + p.equals(new Point(3, 4)));
    }
}

=== 중급 | inheritance | 상속, 인터페이스, 다형성
## 상속
`class Dog extends Animal` — 부모의 필드와 메서드를 물려받습니다. 자바는 **단일 상속**만 지원합니다.

- `super.method()`, `super(...)` 로 부모 호출

## 추상 클래스와 인터페이스
- `abstract class`: 일부 구현을 공유하면서 특정 메서드 구현을 강제
- `interface`: 구현해야 할 메서드 목록(계약). 한 클래스가 **여러 인터페이스를 구현** 가능. Java 8+ 부터 `default` 메서드 제공

## 다형성
부모 타입 변수로 자식 객체를 참조할 수 있고(`Animal a = new Dog();`), 메서드를 호출하면 **실제 객체의 오버라이딩된 메서드**가 실행됩니다. 덕분에 새로운 타입을 추가해도 기존 코드를 바꿀 필요가 없습니다.

## sealed (Java 17+)

--- code
import java.util.List;

public class Poly {
    interface Shape {
        double area();
        default String describe() {           // default 메서드
            return getClass().getSimpleName() + " 넓이=" + String.format("%.2f", area());
        }
    }

    static abstract class Animal {
        protected final String name;
        Animal(String name) { this.name = name; }
        abstract String sound();
        void speak() { System.out.println(name + ": " + sound()); }
    }

    static class Dog extends Animal {
        Dog(String name) { super(name); }
        @Override String sound() { return "멍멍"; }
    }

    static class Cat extends Animal {
        Cat(String name) { super(name); }
        @Override String sound() { return "야옹"; }
    }

    record Circle(double r) implements Shape {
        public double area() { return Math.PI * r * r; }
    }
    record Square(double side) implements Shape {
        public double area() { return side * side; }
    }

    public static void main(String[] args) {
        List<Animal> animals = List.of(new Dog("바둑이"), new Cat("나비"));
        for (Animal a : animals) a.speak();         // 실제 타입의 메서드 호출

        List<Shape> shapes = List.of(new Circle(1), new Square(2));
        shapes.forEach(s -> System.out.println(s.describe()));

        Object o = new Dog("뽀삐");
        if (o instanceof Dog d) {                   // 패턴 매칭 (Java 16+)
            System.out.println(d.name + "는 강아지");
        }
    }
}

=== 중급 | collections | 컬렉션 프레임워크와 제네릭
배열은 길이가 고정이지만 **컬렉션**은 크기가 자동으로 늘어나고 다양한 자료구조를 제공합니다.

## 주요 인터페이스와 구현체
- `List`: 순서 O, 중복 O → `ArrayList`(조회 빠름), `LinkedList`
- `Set`: 중복 X → `HashSet`(순서 없음), `LinkedHashSet`(삽입 순서), `TreeSet`(정렬)
- `Map`: 키-값 → `HashMap`, `LinkedHashMap`, `TreeMap`
- `Queue` / `Deque`: `ArrayDeque`, 우선순위 큐 `PriorityQueue`

## 제네릭
`List<String>` 처럼 담을 타입을 지정해 컴파일 시점에 타입 안정성을 확보합니다. 컬렉션에는 기본형 대신 **래퍼 클래스**(`Integer`, `Double`)를 씁니다(오토박싱).

> 변수 타입은 인터페이스로 선언하세요: `List<String> list = new ArrayList<>();` — 나중에 구현체를 바꾸기 쉽습니다. `List.of()` 로 만든 리스트는 **수정 불가**입니다.
--- code
import java.util.*;

public class Collections1 {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("바나나");
        fruits.add("사과");
        fruits.add("포도");
        fruits.add(0, "딸기");
        fruits.remove("포도");
        Collections.sort(fruits);
        System.out.println(fruits + " 크기=" + fruits.size() + " 첫번째=" + fruits.get(0));

        Set<Integer> unique = new TreeSet<>(List.of(5, 3, 5, 1, 3));
        System.out.println(unique);                 // [1, 3, 5]

        Map<String, Integer> stock = new HashMap<>();
        stock.put("노트북", 5);
        stock.put("마우스", 20);
        stock.merge("마우스", 5, Integer::sum);       // 기존 값에 더하기
        System.out.println(stock.getOrDefault("키보드", 0));
        for (Map.Entry<String, Integer> e : stock.entrySet()) {
            System.out.println(e.getKey() + " → " + e.getValue());
        }

        Map<Character, Integer> freq = new TreeMap<>();
        for (char c : "banana".toCharArray()) freq.put(c, freq.getOrDefault(c, 0) + 1);
        System.out.println(freq);                   // {a=3, b=1, n=2}

        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(1); stack.push(2);
        Queue<String> queue = new ArrayDeque<>(List.of("A", "B"));
        PriorityQueue<Integer> pq = new PriorityQueue<>(List.of(5, 1, 3));
        System.out.println(stack.pop() + " " + queue.poll() + " " + pq.poll());  // 2 A 1
    }
}

=== 중급 | exceptions | 예외 처리
## 예외의 종류
- **Checked 예외** (`IOException`, `SQLException` 등): 컴파일러가 처리를 강제. `try-catch` 하거나 `throws` 로 선언해야 함
- **Unchecked 예외** (`RuntimeException` 하위: `NullPointerException`, `IllegalArgumentException`, `ArithmeticException`): 처리 강제 없음, 주로 프로그래밍 오류
- `Error`: `OutOfMemoryError` 등 복구 불가능한 심각한 문제

## 문법
- `try { } catch (A | B e) { } finally { }` — 멀티 catch
- **try-with-resources**: `try (var r = new FileReader(...)) { }` — `AutoCloseable` 자원을 자동으로 닫음
- `throw new 예외(...)`, 메서드 선언부의 `throws`
- 사용자 정의 예외: `class InsufficientBalanceException extends RuntimeException`

> 예외를 잡고 아무것도 안 하는 `catch (Exception e) {}` 는 버그를 숨깁니다. 최소한 로그를 남기세요.
--- code
import java.io.*;
import java.nio.file.*;
import java.util.List;

public class Exceptions {
    static class InsufficientBalanceException extends RuntimeException {
        InsufficientBalanceException(long need) {
            super("잔액 부족: " + need + "원 더 필요");
        }
    }

    static long withdraw(long balance, long amount) {
        if (amount > balance) throw new InsufficientBalanceException(amount - balance);
        return balance - amount;
    }

    static int parseAge(String s) {
        try {
            return Integer.parseInt(s);
        } catch (NumberFormatException e) {
            System.out.println("숫자가 아님: " + s);
            return -1;
        } finally {
            System.out.println("parseAge 종료");
        }
    }

    public static void main(String[] args) throws IOException {
        System.out.println(parseAge("30") + ", " + parseAge("서른"));

        try {
            withdraw(1000, 5000);
        } catch (InsufficientBalanceException e) {
            System.out.println(e.getMessage());
        }

        Path path = Path.of("memo.txt");
        Files.write(path, List.of("첫 줄", "둘째 줄"));
        try (BufferedReader br = Files.newBufferedReader(path)) {   // 자동으로 close
            String line;
            while ((line = br.readLine()) != null) System.out.println("> " + line);
        }

        try {
            Object o = null;
            o.toString();
        } catch (NullPointerException | ArithmeticException e) {
            System.out.println("잡힘: " + e.getClass().getSimpleName());
        }
    }
}

## 람다와 함수형 인터페이스

import java.util.*;
import java.util.stream.*;

public class Streams {
    record Employee(String name, String dept, int salary) {}

    public static void main(String[] args) {
        List<Employee> emps = List.of(
            new Employee("길동", "개발", 6000),
            new Employee("영희", "개발", 7200),
            new Employee("철수", "영업", 4800),
            new Employee("민수", "영업", 5100),
            new Employee("지수", "디자인", 5500)
        );

        List<String> highPaid = emps.stream()
            .filter(e -> e.salary() >= 5500)
            .sorted(Comparator.comparingInt(Employee::salary).reversed())
            .map(Employee::name)
            .collect(Collectors.toList());
        System.out.println(highPaid);                 // [영희, 길동, 지수]

        Map<String, Double> avgByDept = emps.stream()
            .collect(Collectors.groupingBy(Employee::dept,
                     TreeMap::new, Collectors.averagingInt(Employee::salary)));
        System.out.println(avgByDept);

        int total = emps.stream().mapToInt(Employee::salary).sum();
        String names = emps.stream().map(Employee::name).collect(Collectors.joining(", ", "[", "]"));
        System.out.println(total + " " + names);

        Optional<Employee> designer = emps.stream().filter(e -> e.dept().equals("기획")).findFirst();
        System.out.println(designer.map(Employee::name).orElse("없음"));

        System.out.println(IntStream.rangeClosed(1, 10).filter(n -> n % 2 == 0).boxed().toList());
    }
}

=== 고급 | concurrency | 멀티스레드와 동시성
자바는 처음부터 **멀티스레딩**을 언어 차원에서 지원했습니다.

## 기본 도구
- `Thread`, `Runnable`: 저수준 스레드 생성 (직접 쓰는 경우는 드묾)
- **`ExecutorService`**: 스레드 풀로 작업을 제출하고 관리. `submit()` 은 `Future` 반환
- `CompletableFuture`: 비동기 작업을 조합(`thenApply`, `thenCombine`, `allOf`)

## 동기화 문제
여러 스레드가 같은 변수를 동시에 수정하면 **경쟁 상태(race condition)** 가 생겨 결과가 틀어집니다.
- `synchronized` 메서드/블록: 한 번에 한 스레드만 진입
- `AtomicInteger` 등 원자적 클래스
- `ConcurrentHashMap` 같은 스레드 안전 컬렉션

## 가상 스레드 (Java 21)
`Executors.newVirtualThreadPerTaskExecutor()` 로 수십만 개의 경량 스레드를 만들 수 있어, I/O가 많은 서버 코드를 단순한 동기 스타일로 작성하면서도 높은 처리량을 얻을 수 있습니다.
--- code
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

public class Concurrency {
    static int unsafeCount = 0;

    public static void main(String[] args) throws Exception {
        AtomicInteger safeCount = new AtomicInteger();
        ExecutorService pool = Executors.newFixedThreadPool(4);

        List<Future<?>> futures = new ArrayList<>();
        for (int t = 0; t < 4; t++) {
            futures.add(pool.submit(() -> {
                for (int i = 0; i < 100_000; i++) {
                    unsafeCount++;                 // 경쟁 상태!
                    safeCount.incrementAndGet();   // 원자적 연산
                }
            }));
        }
        for (Future<?> f : futures) f.get();       // 모두 끝날 때까지 대기
        System.out.println("unsafe=" + unsafeCount + " safe=" + safeCount.get());
        // unsafe는 400000보다 작을 수 있음, safe는 항상 400000

        Future<Integer> sum = pool.submit(() -> {
            int s = 0;
            for (int i = 1; i <= 100; i++) s += i;
            return s;
        });
        System.out.println("합계: " + sum.get());
        pool.shutdown();

        CompletableFuture<String> user = CompletableFuture.supplyAsync(() -> "길동");
        CompletableFuture<Integer> point = CompletableFuture.supplyAsync(() -> 1200);
        String msg = user.thenCombine(point, (u, p) -> u + "님 포인트 " + p).get();
        System.out.println(msg);

        try (var vexec = Executors.newVirtualThreadPerTaskExecutor()) {   // Java 21
            for (int i = 0; i < 10_000; i++) {
                vexec.submit(() -> { Thread.sleep(10); return null; });
            }
        }   // 1만 개 작업이 매우 빠르게 완료됨
        System.out.println("가상 스레드 작업 완료");
    }
}

1부터 1,000,000까지의 합을 4개의 작업으로 나누어(각 25만 개씩) `ExecutorService` 로 병렬 계산하고, `Future` 결과를 모아 최종 합계(500000500000)를 출력하세요. 합계는 `long` 을 사용하세요.
--- solution
import java.util.*;
import java.util.concurrent.*;

public class ParallelSum {
    public static void main(String[] args) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(4);
        List<Future<Long>> parts = new ArrayList<>();
        int chunk = 250_000;
        for (int t = 0; t < 4; t++) {
            final long start = (long) t * chunk + 1, end = (long) (t + 1) * chunk;
            parts.add(pool.submit(() -> {
                long s = 0;
                for (long i = start; i <= end; i++) s += i;
                return s;
            }));
        }
        long total = 0;
        for (Future<Long> f : parts) total += f.get();
        pool.shutdown();
        System.out.println(total);   // 500000500000
    }
}

public class ModernJava {
    sealed interface Shape permits Circle, Rect, Triangle {}
    record Circle(double r) implements Shape {}
    record Rect(double w, double h) implements Shape {}
    record Triangle(double b, double h) implements Shape {}

    static double area(Shape s) {
        return switch (s) {                       // switch 패턴 매칭 (Java 21)
            case Circle c -> Math.PI * c.r() * c.r();
            case Rect(double w, double h) -> w * h;          // 레코드 패턴
            case Triangle(var b, var h) -> b * h / 2;
            // sealed이므로 default 없이도 모든 경우가 처리됨을 컴파일러가 확인
        };
    }

    static String classify(Object o) {
        return switch (o) {
            case null -> "null 값";
            case Integer i when i > 100 -> "큰 정수 " + i;
            case Integer i -> "정수 " + i;
            case String s -> "문자열(길이 " + s.length() + ")";
            default -> "기타 " + o.getClass().getSimpleName();
        };
    }

    public static void main(String[] args) {
        Shape[] shapes = { new Circle(1), new Rect(2, 3), new Triangle(4, 5) };
        for (Shape s : shapes) System.out.printf("%s → %.2f%n", s, area(s));

        for (Object o : new Object[]{ 7, 500, "hello", 3.14, null }) {
            System.out.println(classify(o));
        }
    }
}

`sealed interface Expr permits Num, Add, Mul` 과 레코드 `Num(int v)`, `Add(Expr l, Expr r)`, `Mul(Expr l, Expr r)` 를 정의하고, switch 패턴 매칭으로 식을 계산하는 재귀 함수 `eval(Expr e)` 를 작성하세요. `(2 + 3) * 4` 를 계산해 보세요.
--- solution
public class ExprEval {
    sealed interface Expr permits Num, Add, Mul {}
    record Num(int v) implements Expr {}
    record Add(Expr l, Expr r) implements Expr {}
    record Mul(Expr l, Expr r) implements Expr {}

    static int eval(Expr e) {
        return switch (e) {
            case Num n -> n.v();
            case Add(Expr l, Expr r) -> eval(l) + eval(r);
            case Mul(Expr l, Expr r) -> eval(l) * eval(r);
        };
    }

    public static void main(String[] args) {
        Expr expr = new Mul(new Add(new Num(2), new Num(3)), new Num(4));
        System.out.println(eval(expr));   // 20
    }
}
