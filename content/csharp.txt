=== 입문 | hello | C# 시작하기: .NET과 최상위 문
C#(씨샵)은 .NET 런타임 위에서 동작하는 언어입니다. 현재 .NET은 **오픈 소스이며 Windows, macOS, Linux에서 모두 동작**합니다.

## 시작하기
1. .NET SDK 설치 (dotnet.microsoft.com, LTS 버전 권장)

4. IDE: Visual Studio, JetBrains Rider, VS Code(C# Dev Kit)

## 최상위 문 (C# 9+)
예전에는 `class Program { static void Main() { ... } }` 가 필요했지만, 이제는 `Program.cs` 에 코드만 바로 써도 됩니다. 아래 예제는 최상위 문 스타일입니다.

=== 입문 | methods | 메서드와 문자열 처리
## 메서드
- `static int Add(int a, int b) => a + b;` — 식 본문 멤버(`=>`)
- 선택적 매개변수 `int level = 1`, 명명된 인자 `Log(msg: "hi", level: 2)`

## 문자열
`string` 은 불변입니다. `Length`, `ToUpper()`, `Trim()`, `Split()`, `Contains()`, `Replace()`, `Substring()`, `string.Join()`. 반복 연결은 `StringBuilder`. `@"C:\path"` 축자 문자열, `"""` 원시 문자열 리터럴(C# 11).
--- code
using System.Text;

static int Add(int a, int b) => a + b;

static double Average(params int[] nums) => nums.Length == 0 ? 0 : nums.Average();

static (int Min, int Max) MinMax(int[] arr)
{
    int min = arr[0], max = arr[0];
    foreach (var x in arr)
    {
        if (x < min) min = x;
        if (x > max) max = x;
    }
    return (min, max);
}

static void Log(string message, string level = "INFO") =>
    Console.WriteLine($"[{level}] {message}");

Console.WriteLine(Average(90, 80, 70));

Console.WriteLine($"{lo} ~ {hi}");

--- solution
static bool IsPalindrome(string s)
{
    var clean = new string(s.Where(c => !char.IsWhiteSpace(c)).ToArray()).ToLower();
    for (int i = 0, j = clean.Length - 1; i < j; i++, j--)
        if (clean[i] != clean[j]) return false;
    return true;
}

Console.WriteLine(IsPalindrome("Level"));        // True
Console.WriteLine(IsPalindrome("토마토"));        // True
Console.WriteLine(IsPalindrome("never odd or even"));  // True
Console.WriteLine(IsPalindrome("hello"));        // False

=== 초급 | classes | 클래스, 속성, 레코드
## 클래스 구성
- 필드(보통 private), **속성(property)**: `public string Name { get; set; }` — getter/setter를 간결하게
- `init` 접근자: 객체 생성 시에만 설정 가능
- `required` (C# 11): 반드시 초기화해야 하는 속성
- 생성자, **기본 생성자**(C# 12): `class Point(int x, int y)`
- 객체 초기화자: `new Person { Name = "길동", Age = 30 }`

## record
`record Person(string Name, int Age);` — 값 기반 동등성, `ToString`, 분해, `with` 식(일부만 바꾼 복사본)을 자동 제공하는 불변 데이터 타입입니다. DTO, 값 객체에 적합합니다.

## struct vs class
`struct` 는 값 형식(복사됨), `class` 는 참조 형식입니다. 작고 불변인 데이터(좌표, 색상)는 struct가 적합합니다.
--- code
var acc = new BankAccount("길동", 10_000);
acc.Deposit(5_000);
Console.WriteLine(acc.Withdraw(50_000));   // False
Console.WriteLine(acc);

var p1 = new Person("영희", 28);
var p2 = p1 with { Age = 29 };             // 일부만 바꾼 복사본
Console.WriteLine(p1);                      // Person { Name = 영희, Age = 28 }
Console.WriteLine(p1 == new Person("영희", 28));   // True (값 비교)
var (name, age) = p2;
Console.WriteLine($"{name} {age}");

var item = new Product { Name = "키보드", Price = 59000 };
Console.WriteLine($"{item.Name}: {item.Price:N0}원");

public class BankAccount
{
    public string Owner { get; }
    public decimal Balance { get; private set; }     // 외부에서는 읽기만

    public BankAccount(string owner, decimal initial = 0)
    {
        Owner = owner;
        Balance = initial;
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("입금액은 양수여야 합니다");
        Balance += amount;
    }

    public bool Withdraw(decimal amount)
    {
        if (amount > Balance) return false;
        Balance -= amount;
        return true;
    }

    public override string ToString() => $"{Owner}: {Balance:N0}원";
}

public record Person(string Name, int Age);

public class Product
{
    public required string Name { get; init; }
    public decimal Price { get; init; }
}

=== 초급 | collections-linq | 컬렉션과 LINQ
## 컬렉션 (`System.Collections.Generic`)
- `List<T>`: 동적 배열 — `Add`, `Remove`, `Count`, 인덱서
- `Dictionary<TKey, TValue>`: 해시 맵 — `TryGetValue`, `ContainsKey`
- `HashSet<T>`, `Queue<T>`, `Stack<T>`
- 컬렉션 식 (C# 12): `List<int> nums = [1, 2, 3];`

## LINQ (Language Integrated Query)
컬렉션, 데이터베이스, XML 등을 **같은 문법으로 질의**하는 C#의 대표 기능입니다.
- `Where`(필터), `Select`(변환), `OrderBy` / `OrderByDescending`, `GroupBy`
- `First`, `FirstOrDefault`, `Any`, `All`, `Count`, `Sum`, `Average`, `Max`
- `ToList()`, `ToDictionary()` 로 결과를 구체화
- LINQ는 **지연 실행**됩니다. 결과를 열거할 때 비로소 계산됩니다.
--- code
List<Employee> emps =
[
    new("길동", "개발", 6000),
    new("영희", "개발", 7200),
    new("철수", "영업", 4800),
    new("민수", "영업", 5100),
    new("지수", "디자인", 5500),
];

var highPaid = emps.Where(e => e.Salary >= 5500)
                   .OrderByDescending(e => e.Salary)
                   .Select(e => e.Name);
Console.WriteLine(string.Join(", ", highPaid));    // 영희, 길동, 지수

foreach (var g in emps.GroupBy(e => e.Dept))
    Console.WriteLine($"{g.Key}: 평균 {g.Average(e => e.Salary):N0}, {g.Count()}명");

Console.WriteLine(emps.Any(e => e.Dept == "기획"));          // False
Console.WriteLine(emps.Max(e => e.Salary));                  // 7200
var first = emps.FirstOrDefault(e => e.Name.StartsWith("지"));
Console.WriteLine(first?.Name ?? "없음");

// 쿼리 구문 (SQL과 비슷)
var query = from e in emps
            where e.Dept == "영업"
            orderby e.Name
            select new { e.Name, Bonus = e.Salary * 0.1 };
foreach (var x in query) Console.WriteLine($"{x.Name} 보너스 {x.Bonus}");

var stock = new Dictionary<string, int> { ["사과"] = 10, ["배"] = 3 };
stock["포도"] = 7;
if (stock.TryGetValue("배", out int pears)) Console.WriteLine($"배 {pears}개");

record Employee(string Name, string Dept, int Salary);

=== 중급 | oop | 상속, 인터페이스, 다형성
## 상속
`class Dog : Animal` — 단일 클래스 상속. 부모의 `virtual` 메서드를 자식이 `override` 합니다. `abstract` 클래스/메서드는 구현을 강제하고, `sealed` 는 상속을 막습니다. `base` 로 부모 멤버에 접근합니다.

## 인터페이스
`interface IShape { double Area(); }` — 관례적으로 이름 앞에 `I` 를 붙입니다. 클래스는 여러 인터페이스를 구현할 수 있으며, `IComparable<T>`, `IEnumerable<T>`, `IDisposable` 같은 표준 인터페이스를 구현하면 프레임워크와 자연스럽게 연동됩니다.

## 패턴 매칭
`is` 와 `switch` 에서 타입 패턴, 속성 패턴(`{ Age: > 18 }`), 리스트 패턴(`[1, .., var last]`)을 사용할 수 있습니다.
--- code
List<Shape> shapes = [new Circle(1), new Rect(2, 3), new Rect(4, 4)];
foreach (var s in shapes) Console.WriteLine(s.Describe());

shapes.Sort();                                       // IComparable 덕분에 정렬 가능
Console.WriteLine(string.Join(" < ", shapes.Select(s => s.Name)));

foreach (var s in shapes)
{
    string info = s switch
    {
        Circle { Radius: > 5 } => "큰 원",
        Circle c => $"반지름 {c.Radius}인 원",
        Rect { Width: var w, Height: var h } when w == h => "정사각형",
        Rect => "직사각형",
        _ => "알 수 없음"
    };
    Console.WriteLine(info);
}

int[] arr = [1, 2, 3, 9];
if (arr is [1, .., var last]) Console.WriteLine($"1로 시작, 마지막은 {last}");

public abstract class Shape : IComparable<Shape>
{
    public abstract string Name { get; }
    public abstract double Area();
    public virtual string Describe() => $"{Name}: {Area():F2}";
    public int CompareTo(Shape? other) => Area().CompareTo(other?.Area() ?? 0);
}

public class Circle(double radius) : Shape
{
    public double Radius { get; } = radius;
    public override string Name => "원";
    public override double Area() => Math.PI * Radius * Radius;
}

public class Rect(double width, double height) : Shape
{
    public double Width { get; } = width;
    public double Height { get; } = height;

=== 중급 | exceptions-delegates | 예외, 델리게이트, 이벤트
## 예외 처리
`try / catch (특정예외 e) / finally`. `catch (Exception e) when (조건)` 으로 예외 필터도 가능합니다. **`using` 문/선언**은 `IDisposable` 자원을 자동 해제합니다(파일, DB 연결).

## 델리게이트와 람다
델리게이트는 **메서드를 가리키는 타입**입니다. 직접 정의하기보다 내장 타입을 주로 씁니다.
- `Action<T>`: 반환값 없음
- `Func<T, TResult>`: 반환값 있음
- `Predicate<T>`: bool 반환

## 이벤트
`event` 키워드는 델리게이트 기반의 **발행-구독** 패턴입니다. Unity와 WinForms/WPF의 버튼 클릭 처리가 대표적인 예입니다. 외부에서는 `+=` / `-=` 로 구독만 할 수 있고 직접 호출은 할 수 없습니다.

=== 고급 | generics | 제네릭과 확장 메서드
## 제네릭
`class Repository<T>`, `T Max<T>(T a, T b)` 처럼 타입을 매개변수로 받습니다. C#의 제네릭은 런타임에도 타입 정보가 유지됩니다(자바의 타입 소거와 다름).

## 제약 조건 (where)
- `where T : class` / `struct` / `new()` / `notnull`
- `where T : IComparable<T>` — 특정 인터페이스 구현 요구
- `where T : BaseClass`
- 제네릭 수학(C# 11): `where T : INumber<T>` 로 모든 숫자 타입에 동작하는 함수

## 확장 메서드
`static` 클래스의 `static` 메서드 첫 매개변수에 `this` 를 붙이면, 기존 타입에 메서드를 **추가한 것처럼** 호출할 수 있습니다. LINQ의 `Where`, `Select` 가 모두 `IEnumerable<T>` 의 확장 메서드입니다.
--- code
using System.Numerics;

var repo = new Repository<User>();
repo.Add(new User(1, "길동"));
repo.Add(new User(2, "영희"));
Console.WriteLine(repo.GetById(2)?.Name);       // 영희
Console.WriteLine(repo.Count);

Console.WriteLine(Util.MaxOf(3, 9));            // 9
Console.WriteLine(Util.MaxOf("apple", "banana"));
Console.WriteLine(Util.Sum(new[] { 1, 2, 3 }));         // 6
Console.WriteLine(Util.Sum(new[] { 1.5, 2.5 }));        // 4

Console.WriteLine("hello world".ToTitleCase());          // Hello World
var nums = new[] { 1, 2, 3, 4, 5, 6 };
Console.WriteLine(string.Join(",", nums.EveryNth(2)));    // 1,3,5

public interface IEntity { int Id { get; } }
public record User(int Id, string Name) : IEntity;

public class Repository<T> where T : IEntity
{
    private readonly Dictionary<int, T> _items = new();
    public void Add(T item) => _items[item.Id] = item;
    public T? GetById(int id) => _items.TryGetValue(id, out var v) ? v : default;
    public int Count => _items.Count;
}

public static class Util
{
    public static T MaxOf<T>(T a, T b) where T : IComparable<T> =>
        a.CompareTo(b) >= 0 ? a : b;

    public static T Sum<T>(IEnumerable<T> items) where T : INumber<T>
    {
        T total = T.Zero;
        foreach (var x in items) total += x;
        return total;
    }

    public static string ToTitleCase(this string s) =>
        string.Join(" ", s.Split(' ').Select(w => w.Length == 0 ? w : char.ToUpper(w[0]) + w[1..]));

    public static IEnumerable<T> EveryNth<T>(this IEnumerable<T> source, int n)
    {
        int i = 0;
        foreach (var item in source)
            if (i++ % n == 0) yield return item;
    }
}

public static class Ext
{
    public static IEnumerable<List<T>> Batch<T>(this IEnumerable<T> source, int size)
    {
        var bucket = new List<T>(size);
        foreach (var item in source)
        {
            bucket.Add(item);
            if (bucket.Count == size)
            {
                yield return bucket;
                bucket = new List<T>(size);
            }
        }
        if (bucket.Count > 0) yield return bucket;
    }
}

=== 고급 | async | 비동기 프로그래밍: async/await와 Task
C#은 `async` / `await` 를 처음 대중화한 언어입니다. I/O 작업(네트워크, 파일, DB)을 기다리는 동안 **스레드를 차단하지 않아** 서버는 더 많은 요청을, UI 앱은 멈추지 않고 동작할 수 있습니다.

## 핵심
- `async Task<T>` 메서드: 비동기적으로 T를 반환. 반환값이 없으면 `Task`
- `await`: 작업이 끝날 때까지 기다리되 스레드는 다른 일을 함
- `Task.WhenAll(...)`: 여러 작업을 동시에 실행하고 모두 기다림, `Task.WhenAny`: 가장 먼저 끝난 것
- `CancellationToken`: 작업 취소
- `Task.Run`: CPU 작업을 스레드 풀로 넘김
- `IAsyncEnumerable<T>` + `await foreach`: 비동기 스트림

> `async void` 는 이벤트 핸들러 외에는 쓰지 마세요(예외를 잡을 수 없음). `.Result` 나 `.Wait()` 로 동기 대기하면 교착 상태가 생길 수 있습니다.
--- code
using System.Diagnostics;

async Task<string> FetchAsync(string name, int ms, CancellationToken ct = default)
{
    Console.WriteLine($"{name} 요청 시작");
    await Task.Delay(ms, ct);             // 네트워크 대기를 흉내
    return $"{name} 응답 ({ms}ms)";
}

var sw = Stopwatch.StartNew();
string[] results = await Task.WhenAll(
    FetchAsync("A", 300), FetchAsync("B", 200), FetchAsync("C", 100));
Console.WriteLine(string.Join(", ", results));
Console.WriteLine($"총 {sw.ElapsedMilliseconds}ms (순차였다면 600ms)");

using var cts = new CancellationTokenSource(150);
try
{
    await FetchAsync("느린 서버", 1000, cts.Token);
}
catch (OperationCanceledException)
{
    Console.WriteLine("시간 초과로 취소됨");
}

await foreach (var n in CountAsync(3))
    Console.WriteLine($"스트림 값: {n}");

int heavy = await Task.Run(() => Enumerable.Range(1, 1_000_000).Sum(x => x % 7));
Console.WriteLine($"CPU 작업 결과: {heavy}");

async IAsyncEnumerable<int> CountAsync(int n)
{
    for (int i = 1; i <= n; i++)
    {
        await Task.Delay(50);
        yield return i;
    }
}
