=== 입문 | hello | Rust 시작하기: Cargo와 Hello World
Rust는 모질라에서 시작된 시스템 프로그래밍 언어로, **"빠르고, 안전하고, 동시성에 강한"** 소프트웨어를 목표로 합니다. 리눅스 커널, 윈도우, 안드로이드, 클라우드플레어 등에서 C/C++을 대체하며 쓰이고 있습니다.

## 설치와 Cargo
- rustup.rs 의 설치 스크립트로 `rustup` 설치 → `rustc --version`
- **Cargo**: 빌드 도구 + 패키지 관리자
  - `cargo new hello` 프로젝트 생성
  - `cargo run` 빌드 후 실행, `cargo build --release` 최적화 빌드
  - `cargo check` 빠른 컴파일 검사, `cargo test`, `cargo fmt`, `cargo clippy`(린트)
- 외부 라이브러리(crate)는 `Cargo.toml` 의 `[dependencies]` 에 추가 (crates.io)

`println!` 끝의 `!` 는 함수가 아니라 **매크로**라는 표시입니다. `{}` 자리에 값이 들어가고, `{:?}` 는 디버그 출력입니다.
--- code
fn main() {
    println!("Hello, World!");
    let name = "길동";
    let year = 2015;
    println!("{}님, Rust 1.0은 {}년에 출시되었습니다.", name, year);
    println!("{name}님 안녕하세요!");          // 변수 이름을 직접 넣기 (2021 에디션)
    println!("{:.2} / {:>5}| / {:?}", 3.14159, 42, vec![1, 2, 3]);
    eprintln!("에러 출력은 표준 에러로");
}

=== 입문 | variables | 변수, 불변성, 자료형
## 변수는 기본적으로 불변
`let x = 5;` 로 만든 변수는 바꿀 수 없습니다. 바꾸려면 `let mut x = 5;` 처럼 **명시적으로 `mut`** 를 붙입니다. 이 설계 덕분에 의도치 않은 변경 버그가 줄어듭니다.

## 섀도잉
같은 이름으로 `let` 을 다시 쓰면 새 변수가 이전 변수를 가립니다. 타입도 바꿀 수 있습니다: `let spaces = "   "; let spaces = spaces.len();`

## 스칼라 타입
- 정수: `i8`~`i128`, `u8`~`u128`, `isize`/`usize`(포인터 크기, 인덱스용). 기본은 `i32`
- 실수: `f64`(기본), `f32`
- `bool`, `char`(4바이트 유니코드 스칼라 — 한글 한 글자도 char 하나)

## 복합 타입
- 튜플 `(i32, f64, char)` — `t.0` 으로 접근, 구조 분해 가능
- 배열 `[i32; 5]` — 고정 길이. 범위를 벗어난 접근은 **패닉**(C처럼 조용히 메모리를 침범하지 않음)

> 디버그 빌드에서 정수 오버플로는 패닉이 발생합니다. 의도적인 래핑은 `wrapping_add`, 검사는 `checked_add` 를 사용하세요.
--- code
fn main() {
    let x = 5;
    // x = 6;                 // ❌ 컴파일 오류: 불변 변수에 재할당
    let mut count = 0;
    count += 1;

    let spaces = "   ";
    let spaces = spaces.len(); // 섀도잉: &str → usize
    println!("x={x} count={count} spaces={spaces}");

    let big: u64 = 10_000_000_000;
    let pi = 3.14_f32;
    let ch = '한';
    let ok: bool = true;
    println!("{big} {pi} {ch} {ok} char크기={}바이트", std::mem::size_of::<char>());

    let tup: (i32, f64, &str) = (500, 6.4, "rust");
    let (a, b, c) = tup;
    println!("{a} {b} {c} / {}", tup.0);

    let arr = [10, 20, 30, 40, 50];
    let zeros = [0u8; 4];          // [0, 0, 0, 0]
    println!("{:?} 길이={} {:?}", arr, arr.len(), zeros);

    let max = u8::MAX;             // 255
    println!("{:?} {:?} {}", max.checked_add(1), 200u8.checked_add(50), max.wrapping_add(1));
    // None Some(250) 0

    let n = 7 / 2;                 // 3 (정수 나눗셈)
    let f = 7.0 / 2.0;             // 3.5
    let cast = 3.99_f64 as i32;    // 3 (as로 명시적 변환)
    println!("{n} {f} {cast}");
}

=== 입문 | control | 함수와 제어 흐름
## 함수
`fn add(a: i32, b: i32) -> i32 { a + b }` — 매개변수 타입은 필수입니다. 함수 본문의 **마지막 식**(세미콜론 없음)이 반환값이 됩니다. 세미콜론을 붙이면 문(statement)이 되어 `()` 를 반환합니다. 조기 반환은 `return`.

## if는 식(expression)
`let grade = if score >= 90 { "A" } else { "B" };` 처럼 값을 만들 수 있습니다. 조건은 반드시 `bool` 이어야 합니다(정수 자동 변환 없음).

## 반복문
- `loop { }` — 무한 루프. `break 값;` 으로 값을 반환할 수 있음
- `while 조건 { }`
- `for x in 반복자 { }` — 범위 `1..10`(10 미포함), `1..=10`(포함), `.rev()` 역순
- 라벨: `'outer: loop { break 'outer; }`

## match
값을 패턴과 비교하는 강력한 분기입니다. **모든 경우를 처리해야** 컴파일됩니다(완전성 검사).
--- code
fn add(a: i32, b: i32) -> i32 {
    a + b // 세미콜론 없음 → 반환값
}

fn classify(n: i32) -> &'static str {
    match n {
        i32::MIN..=-1 => "음수",
        0 => "영",
        1..=9 => "한 자리 양수",
        _ => "큰 양수",
    }
}

fn main() {
    println!("{}", add(2, 3));

    let score = 85;
    let grade = if score >= 90 { "A" } else if score >= 80 { "B" } else { "C" };
    println!("{grade}");

    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2; // loop가 값을 반환
        }
    };
    println!("result = {result}");

    for i in (1..=3).rev() {
        print!("{i}... ");
    }
    println!("발사!");

    for n in [-5, 0, 7, 42] {
        println!("{n}: {}", classify(n));
    }

    let pair = (0, -2);
    match pair {
        (0, y) => println!("y축 위의 점, y={y}"),
        (x, 0) => println!("x축 위의 점, x={x}"),
        _ => println!("어느 축에도 없음"),
    }
}
--- exercise
정수 n을 받아 n번째 피보나치 수를 반환하는 `fn fib(n: u32) -> u64` 를 반복문으로 작성하고, `match` 를 사용해 1~3월은 "1분기", 4~6월은 "2분기" ... 를 반환하는 `fn quarter(month: u32) -> &'static str` 도 작성하세요(범위 밖은 "잘못된 월").
--- solution
fn fib(n: u32) -> u64 {
    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        (a, b) = (b, a + b);
    }
    a
}

fn quarter(month: u32) -> &'static str {
    match month {
        1..=3 => "1분기",
        4..=6 => "2분기",
        7..=9 => "3분기",
        10..=12 => "4분기",
        _ => "잘못된 월",
    }
}

fn main() {
    println!("{} {}", fib(10), fib(50)); // 55 12586269025
    println!("{} {}", quarter(5), quarter(13));
}

=== 초급 | ownership | 소유권: Rust의 핵심
**소유권(ownership)** 은 가비지 컬렉터 없이 메모리 안전성을 보장하는 Rust만의 시스템입니다.

## 소유권 규칙 3가지
1. 모든 값에는 **소유자**인 변수가 하나 있다.
2. 한 번에 **소유자는 하나**뿐이다.
3. 소유자가 스코프를 벗어나면 값은 **자동으로 해제(drop)** 된다.

## 이동(move)
힙 데이터를 가진 `String` 을 다른 변수에 대입하거나 함수에 넘기면 소유권이 **이동**하고, 원래 변수는 더 이상 쓸 수 없습니다. 덕분에 이중 해제가 원천 차단됩니다.

## 복사(Copy)
정수, 실수, bool, char 같은 스택 전용 타입은 `Copy` 트레이트를 가져 대입 시 값이 복사되고 원본도 계속 쓸 수 있습니다.

## clone
힙 데이터까지 깊은 복사가 필요하면 `.clone()` 을 명시적으로 호출합니다. 비용이 드는 연산이 코드에 드러나게 하는 설계입니다.
--- code
fn take_ownership(s: String) {
    println!("받은 값: {s}");
} // 여기서 s가 drop됨

fn make_greeting(name: &str) -> String {
    format!("안녕하세요, {name}님") // 소유권을 호출자에게 반환
}

fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 소유권 이동: s1은 무효
    // println!("{s1}");   // ❌ 컴파일 오류: borrow of moved value: `s1`
    println!("{s2}");

    let s3 = s2.clone(); // 깊은 복사: 둘 다 유효
    println!("{s2} {s3}");

    take_ownership(s3);
    // println!("{s3}");   // ❌ s3는 함수로 이동됨

    let x = 5;
    let y = x; // i32는 Copy: x도 계속 사용 가능
    println!("{x} {y}");

    let g = make_greeting("길동");
    println!("{g}");

    {
        let temp = String::from("임시");
        println!("{temp}");
    } // temp가 여기서 자동 해제 (free 호출 불필요)
}
--- exercise

--- solution
// 원인: text의 소유권이 length 함수로 이동되어 이후 text를 사용할 수 없음

// 방법 1: clone으로 복사본을 넘김 (비용 발생)
fn length(s: String) -> usize { s.len() }

// 방법 2: 소유권을 튜플로 돌려받음 (번거로움 → 다음 레슨의 "빌림"이 정답!)
fn length_and_back(s: String) -> (String, usize) {
    let n = s.len();
    (s, n)
}

fn main() {
    let text = String::from("소유권");
    let n = length(text.clone());
    println!("{text}의 길이는 {n}");          // 9 (UTF-8 바이트)

    let (text, n) = length_and_back(text);
    println!("{text}의 길이는 {n}");
}

=== 초급 | borrowing | 참조와 빌림, 슬라이스
소유권을 넘기지 않고 값을 사용하려면 **참조(&)** 로 **빌려(borrow)** 줍니다.

## 빌림 규칙 (컴파일러의 빌림 검사기가 강제)
- **불변 참조 `&T`** 는 동시에 여러 개 가능
- **가변 참조 `&mut T`** 는 한 번에 **딱 하나**, 그리고 그동안 불변 참조도 없어야 함
- 참조는 항상 **유효한 값**을 가리켜야 함 (댕글링 참조 불가)

이 규칙이 **데이터 경쟁을 컴파일 시점에 차단**합니다. "읽는 사람이 여럿이거나, 쓰는 사람이 하나이거나."

## 슬라이스
컬렉션의 일부를 가리키는 참조입니다.
- 문자열 슬라이스 `&str`: `&s[0..5]`. 문자열 리터럴도 `&str`
- 배열 슬라이스 `&[i32]`
- 함수 매개변수는 `&String` 보다 `&str`, `&Vec<T>` 보다 `&[T]` 를 받는 것이 더 범용적입니다.
--- code
fn length(s: &str) -> usize {
    s.len() // 빌렸을 뿐, 소유권은 그대로
}

fn add_exclamation(s: &mut String) {
    s.push_str("!");
}

fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

fn sum(nums: &[i32]) -> i32 {
    nums.iter().sum()
}

fn main() {
    let mut text = String::from("hello world");
    println!("길이: {}", length(&text));
    println!("원본 여전히 사용 가능: {text}");

    add_exclamation(&mut text);
    println!("{text}");                       // hello world!

    let r1 = &text;
    let r2 = &text;                           // 불변 참조 여러 개 OK
    println!("{r1} / {r2}");
    // let r3 = &mut text;                    // r1, r2가 아래에서 쓰인다면 ❌

    let r3 = &mut text;                       // r1, r2를 더 이상 쓰지 않으므로 OK (NLL)
    r3.make_ascii_uppercase();
    println!("{text}");

    let word = first_word(&text);
    println!("첫 단어: {word}");

    let arr = [1, 2, 3, 4, 5];
    println!("{} {}", sum(&arr), sum(&arr[1..4])); // 15 9
    let v = vec![10, 20];
    println!("{}", sum(&v));                  // Vec도 &[i32]로 전달 가능
}

enum AppError {
    Parse(ParseIntError),
    Negative(i64),
}

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            AppError::Parse(e) => write!(f, "숫자 변환 실패: {e}"),
            AppError::Negative(n) => write!(f, "음수는 안 됨: {n}"),
        }
    }

impl From<ParseIntError> for AppError {
    fn from(e: ParseIntError) -> Self {
        AppError::Parse(e)
    }

fn parse_positive(s: &str) -> Result<i64, AppError> {
    let n: i64 = s.trim().parse()?; // 실패 시 From으로 변환되어 즉시 반환
    if n < 0 {
        return Err(AppError::Negative(n));
    }
    Ok(n)
}

## 트레이트(trait)
타입이 가져야 할 **공통 동작**을 정의합니다(다른 언어의 인터페이스와 비슷). 기본 구현을 제공할 수도 있습니다. `Display`, `Debug`, `Clone`, `Iterator`, `From` 등 표준 트레이트를 구현하면 언어 기능과 자연스럽게 연동됩니다.

## 제네릭과 트레이트 경계
`fn largest<T: PartialOrd + Copy>(list: &[T]) -> T` 또는 `where` 절. 컴파일 시 타입별로 코드가 생성되어(단형화) **런타임 비용이 없습니다**.
- `impl Trait` 인자/반환: `fn print(x: impl Display)`
- 동적 디스패치: `Box<dyn Trait>` — 서로 다른 타입을 한 컬렉션에

## 반복자와 클로저
`iter()` → `map`, `filter`, `enumerate`, `zip`, `take`, `sum`, `collect` 체인. 반복자는 **지연 평가**되며, 최적화 후 손으로 짠 루프만큼 빠릅니다(제로 비용 추상화). 클로저 `|x| x * 2` 는 주변 변수를 캡처합니다.

            max = x;
        }

    max

=== 고급 | lifetimes-smart | 라이프타임과 스마트 포인터
## 라이프타임
참조가 **얼마나 오래 유효한지**를 나타내는 컴파일러의 개념입니다. 대부분 자동 추론(생략 규칙)되지만, 함수가 여러 참조를 받아 참조를 반환할 때는 명시가 필요할 수 있습니다.
`fn longest<'a>(x: &'a str, y: &'a str) -> &'a str` — "반환값은 x, y 중 더 짧게 사는 것만큼 유효하다"는 뜻. 라이프타임은 수명을 바꾸지 않고 **관계를 설명**할 뿐입니다.

## 스마트 포인터
- `Box<T>`: 힙 할당, 단일 소유. 재귀 타입(트리, 리스트)에 필수
- `Rc<T>`: 참조 카운트로 **여러 소유자** (싱글 스레드)
- `Arc<T>`: 원자적 참조 카운트 (멀티 스레드)
- `RefCell<T>`: 빌림 규칙을 **런타임에** 검사 → 불변 참조를 통해서도 내부 수정(내부 가변성)
- 자주 쓰는 조합: `Rc<RefCell<T>>`(싱글 스레드 공유 가변), `Arc<Mutex<T>>`(멀티 스레드 공유 가변)
--- code
use std::cell::RefCell;
use std::rc::Rc;

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() >= y.len() { x } else { y }
}

struct Excerpt<'a> {
    part: &'a str, // 구조체가 참조를 가지면 라이프타임 명시 필요
}

#[derive(Debug)]
enum List {
    Cons(i32, Box<List>), // Box 없이는 크기를 알 수 없는 재귀 타입
    Nil,
}
use List::{Cons, Nil};

fn sum_list(l: &List) -> i32 {
    match l {
        Cons(v, rest) => v + sum_list(rest),
        Nil => 0,
    }
}

#[derive(Debug)]
struct Account {
    balance: i32,
}

fn main() {
    let a = String::from("긴 문자열입니다");
    let result;
    {
        let b = String::from("짧음");
        result = longest(&a, &b);
        println!("더 긴 것: {result}");
    }
    // println!("{result}"); // ❌ b가 이미 해제되어 result가 유효하지 않을 수 있음

    let novel = String::from("첫 문장. 두 번째 문장.");
    let ex = Excerpt { part: novel.split('.').next().unwrap() };
    println!("발췌: {}", ex.part);

    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));
    println!("리스트 합: {}", sum_list(&list));

    let shared = Rc::new(RefCell::new(Account { balance: 100 }));
    let owner1 = Rc::clone(&shared);
    let owner2 = Rc::clone(&shared);
    owner1.borrow_mut().balance += 50;
    owner2.borrow_mut().balance -= 30;
    println!("{:?}, 소유자 수 = {}", shared.borrow(), Rc::strong_count(&shared)); // 120, 3
}

--- solution
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

impl Node {
    fn leaf(value: i32) -> Option<Box<Node>> {
        Some(Box::new(Node { value, left: None, right: None }))
    }
    fn sum(&self) -> i32 {
        self.value
            + self.left.as_ref().map_or(0, |n| n.sum())
            + self.right.as_ref().map_or(0, |n| n.sum())
    }
    fn depth(&self) -> usize {
        let l = self.left.as_ref().map_or(0, |n| n.depth());
        let r = self.right.as_ref().map_or(0, |n| n.depth());
        1 + l.max(r)
    }
}

fn main() {
    let tree = Node {
        value: 1,
        left: Some(Box::new(Node { value: 2, left: Node::leaf(4), right: None })),
        right: Node::leaf(3),
    };
    println!("합={} 깊이={}", tree.sum(), tree.depth()); // 합=10 깊이=3
}

=== 고급 | concurrency | 두려움 없는 동시성
Rust의 소유권과 타입 시스템은 **데이터 경쟁을 컴파일 시점에 막아 줍니다**. 이를 "두려움 없는 동시성(fearless concurrency)"이라고 부릅니다.

## 도구
- `std::thread::spawn(move || { ... })` — `move` 클로저로 소유권을 스레드에 넘김
- `std::thread::scope` — 지역 변수를 안전하게 빌려 쓰는 스코프 스레드
- 채널 `std::sync::mpsc` — 메시지 전달 (다중 생산자, 단일 소비자)
- `Arc<Mutex<T>>` — 공유 상태. `lock()` 이 반환하는 가드가 스코프를 벗어나면 자동 해제
- `Send`(스레드 간 이동 가능), `Sync`(스레드 간 공유 가능) 마커 트레이트를 컴파일러가 자동 검사 — `Rc` 를 스레드에 넘기려 하면 컴파일 오류

## async
`async fn` / `.await` 로 비동기 I/O를 작성하며, 실행기(런타임)로 **tokio** 크레이트를 가장 많이 씁니다. 웹 프레임워크 axum, actix-web 등이 이를 기반으로 합니다.

## 데이터 병렬
`rayon` 크레이트를 쓰면 `iter()` 를 `par_iter()` 로 바꾸는 것만으로 병렬 처리가 됩니다.
--- code
use std::sync::mpsc;
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::Duration;

fn main() {
    // 1) 스레드 생성과 join
    let handles: Vec<_> = (1..=3)
        .map(|id| {
            thread::spawn(move || {
                thread::sleep(Duration::from_millis(30 * id));
                id * id
            })
        })
        .collect();
    let results: Vec<u64> = handles.into_iter().map(|h| h.join().unwrap()).collect();
    println!("결과: {:?}", results); // [1, 4, 9]

    // 2) 채널로 메시지 전달
    let (tx, rx) = mpsc::channel();
    for id in 0..3 {
        let tx = tx.clone();
        thread::spawn(move || {
            tx.send(format!("작업자 {id} 완료")).unwrap();
        });
    }
    drop(tx); // 원본 송신자를 닫아야 수신 루프가 끝남
    for msg in rx {
        println!("{msg}");
    }

    // 3) 공유 상태: Arc<Mutex<T>>
    let counter = Arc::new(Mutex::new(0));
    let mut hs = vec![];
    for _ in 0..8 {
        let c = Arc::clone(&counter);
        hs.push(thread::spawn(move || {
            for _ in 0..1000 {
                *c.lock().unwrap() += 1;
            }
        }));
    }
    for h in hs {
        h.join().unwrap();
    }
    println!("counter = {}", *counter.lock().unwrap()); // 항상 8000

    // 4) 스코프 스레드: 지역 데이터를 빌려서 병렬 처리
    let data = vec![1, 2, 3, 4, 5, 6, 7, 8];
    let (left, right) = data.split_at(data.len() / 2);
    let (a, b) = thread::scope(|s| {
        let h1 = s.spawn(|| left.iter().sum::<i32>());
        let h2 = s.spawn(|| right.iter().sum::<i32>());
        (h1.join().unwrap(), h2.join().unwrap())
    });
    println!("부분합 {a} + {b} = {}", a + b); // 10 + 26 = 36
}

1부터 1,000,000까지의 수를 4개의 스레드가 나누어 합을 구하고(각자 25만 개), 채널(`mpsc`)로 부분합을 보내 main에서 최종 합계(500000500000, `u64`)를 출력하세요.
--- solution
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel::<u64>();
    let chunk = 250_000u64;
    for t in 0..4u64 {
        let tx = tx.clone();
        thread::spawn(move || {
            let start = t * chunk + 1;
            let end = (t + 1) * chunk;
            let partial: u64 = (start..=end).sum();
            tx.send(partial).unwrap();
        });
    }
    drop(tx);
    let total: u64 = rx.iter().sum();
    println!("{total}"); // 500000500000
}
