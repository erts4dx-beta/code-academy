=== 입문 | hello | PHP 시작하기
PHP(PHP: Hypertext Preprocessor)는 웹 서버에서 실행되어 HTML을 만들어 내는 언어입니다. WordPress, Wikipedia(MediaWiki), Laravel 프레임워크 등이 PHP로 만들어졌습니다.

## 실행 방법
- 명령줄: `php hello.php`
- 내장 웹 서버: `php -S localhost:8000` 후 브라우저에서 접속
- 설치 없이: 3v4l.org, onlinephp.io

## 기본 문법
- PHP 코드는 `<?php` 로 시작합니다. 파일 전체가 PHP라면 닫는 태그 `?>` 는 생략하는 것이 관례입니다.
- 문장 끝에 세미콜론 `;` 필수
- 변수는 `$` 로 시작: `$name`
- 출력: `echo`, `print`, 디버깅용 `var_dump()`, `print_r()`
- 큰따옴표 문자열 안에서는 변수가 치환되고, 작은따옴표는 그대로 출력됩니다.
--- code
<?php
echo "Hello, World!\n";

$name = "길동";
$year = 2026;
echo "안녕하세요, {$name}님! 올해는 {$year}년입니다.\n";
echo '작은따옴표: $name 은 치환되지 않음' . "\n";
echo "이어 붙이기: " . $name . "\n";   // . 은 문자열 연결 연산자

var_dump($year);        // int(2026)
var_dump(3.14, true);   // float(3.14) bool(true)

=== 입문 | types | 자료형과 연산자
## 자료형
`int`, `float`, `string`, `bool`, `array`, `null`, `object`. PHP는 동적 타입 언어로, 값에 따라 타입이 정해집니다. `gettype()`, `var_dump()` 로 확인합니다.

## 비교: == vs ===
- `==` 느슨한 비교: 타입 변환 후 비교 (`"10" == 10` → true)
- `===` 엄격한 비교: 타입과 값 모두 비교 (`"10" === 10` → false)
- **항상 `===` 사용을 권장**합니다.

## 유용한 연산자
- null 병합 `??`: `$_GET['page'] ?? 1`
- 우주선 `<=>`: 작으면 -1, 같으면 0, 크면 1 (정렬에 사용)
- 거듭제곱 `**`, 정수 나눗셈 `intdiv()`, 나머지 `%`
- 형 변환: `(int)"42"`, `(string)3.5`, `intval()`
--- code
<?php
$i = 42;
$f = 3.14;
$s = "hello";
$b = false;
$n = null;
echo gettype($i), " ", gettype($f), " ", gettype($s), " ", gettype($b), " ", gettype($n), "\n";

var_dump("10" == 10);    // bool(true)  — 느슨한 비교
var_dump("10" === 10);   // bool(false) — 엄격한 비교
var_dump(0 == "a");      // bool(false) — PHP 8부터 변경됨 (7에서는 true!)

echo 7 / 2, "\n";            // 3.5
echo intdiv(7, 2), "\n";     // 3
echo 7 % 3, "\n";            // 1
echo 2 ** 10, "\n";          // 1024

echo 1 <=> 2, " ", 2 <=> 2, " ", 3 <=> 2, "\n";   // -1 0 1

$config = ['theme' => 'dark'];
echo $config['lang'] ?? 'ko', "\n";          // 키가 없으면 기본값

echo (int)"123abc", "\n";    // 123
echo (int)"abc", "\n";       // 0
var_dump((bool)"0", (bool)"", (bool)"false");   // false false true
--- exercise
`$a = "5"`, `$b = 5`, `$c = 5.0` 에 대해 `==` 와 `===` 비교 결과를 `var_dump` 로 모두 확인하고, 정수 17을 5로 나눈 몫과 나머지를 출력하세요.
--- solution
<?php

var_dump($a == $b, $a === $b);   // true false
var_dump($b == $c, $b === $c);   // true false (int vs float)
echo "몫: " . intdiv(17, 5) . ", 나머지: " . (17 % 5) . "\n";   // 3, 2
--- quiz

- true
+ false
- 오류
- null
! ===는 타입까지 비교하므로 문자열과 정수는 다릅니다.
? `$x = $arr['key'] ?? 'default';` 에서 `??` 의 역할은?
+ 왼쪽 값이 존재하지 않거나 null이면 오른쪽 값을 사용
- 두 값을 비교

- 배열을 합침

=== 입문 | control | 조건문과 반복문
## 조건문
- `if / elseif / else`
- `switch` (느슨한 비교, break 필요)
- **`match` (PHP 8)**: 엄격한 비교, 값을 반환하는 식, break 불필요 — switch보다 권장

## 반복문
- `for ($i = 0; $i < 10; $i++)`
- `while`, `do-while`
- **`foreach`**: 배열 순회의 기본 — `foreach ($arr as $value)`, `foreach ($arr as $key => $value)`
- `break`, `continue`
--- code
<?php
$score = 85;
if ($score >= 90) {
    $grade = "A";
} elseif ($score >= 80) {
    $grade = "B";
} else {
    $grade = "C";
}
echo "학점: $grade\n";

$status = 404;
$message = match ($status) {
    200, 201 => "성공",
    404 => "찾을 수 없음",
    500 => "서버 오류",
    default => "알 수 없음",
};
echo $message, "\n";

$level = match (true) {
    $score >= 90 => "우수",
    $score >= 70 => "보통",
    default => "노력 필요",
};
echo $level, "\n";

for ($i = 1; $i <= 5; $i++) {
    if ($i === 3) continue;
    echo $i, " ";
}
echo "\n";

$fruits = ["사과", "바나나", "포도"];
foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}

$n = 1;
while ($n < 100) {
    $n *= 3;
}
echo $n, "\n";   // 243

=== 초급 | arrays | 배열 (인덱스·연관 배열)
PHP의 배열은 **순서 있는 맵**입니다. 하나의 타입으로 리스트, 딕셔너리, 스택, 큐 역할을 모두 합니다.

## 생성
- 인덱스 배열: `$nums = [1, 2, 3];`
- 연관 배열: `$user = ['name' => '길동', 'age' => 30];`
- 추가: `$nums[] = 4;`

## 주요 함수
- `count`, `in_array`, `array_key_exists`, `array_search`
- `array_push/pop`, `array_shift/unshift`, `array_slice`, `array_merge`
- 함수형: `array_map`, `array_filter`, `array_reduce`
- 정렬: `sort`/`rsort`(값), `asort`/`arsort`(값, 키 유지), `ksort`(키), `usort`(사용자 비교)
- 구조 분해: `[$a, $b] = [1, 2];`, `['name' => $n] = $user;`
- 스프레드: `[...$a, ...$b]`
--- code
<?php
$nums = [5, 3, 8, 1];
$nums[] = 9;
echo count($nums), "\n";              // 5
sort($nums);
echo implode(", ", $nums), "\n";      // 1, 3, 5, 8, 9

$user = ['name' => '길동', 'age' => 30, 'city' => '서울'];
$user['email'] = 'gd@example.com';
foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
var_dump(array_key_exists('age', $user), in_array('서울', $user));

$squares = array_map(fn($n) => $n * $n, $nums);
$evens = array_filter($nums, fn($n) => $n % 2 === 0);
$sum = array_reduce($nums, fn($carry, $n) => $carry + $n, 0);
echo implode(" ", $squares), " | ", implode(" ", $evens), " | $sum\n";

$products = [
    ['name' => '키보드', 'price' => 45000],
    ['name' => '마우스', 'price' => 25000],
    ['name' => '모니터', 'price' => 230000],
];
usort($products, fn($a, $b) => $a['price'] <=> $b['price']);
echo implode(", ", array_column($products, 'name')), "\n";   // 마우스, 키보드, 모니터

['name' => $name, 'city' => $city] = $user;
echo "$name / $city\n";

$merged = [...[1, 2], ...[3, 4]];
print_r($merged);
--- exercise
학생 점수 연관 배열 `['철수' => 85, '영희' => 92, '민수' => 78, '지우' => 95]` 에서 (1) 평균을 소수점 1자리로, (2) 점수 내림차순으로 정렬해 "이름: 점수" 출력, (3) 90점 이상 학생 이름 목록을 출력하세요.
--- solution
<?php
$scores = ['철수' => 85, '영희' => 92, '민수' => 78, '지우' => 95];
printf("평균: %.1f\n", array_sum($scores) / count($scores));   // 87.5

arsort($scores);   // 값 기준 내림차순, 키 유지
foreach ($scores as $name => $score) {
    echo "$name: $score\n";
}

$top = array_keys(array_filter($scores, fn($s) => $s >= 90));
echo implode(", ", $top), "\n";   // 지우, 영희

=== 초급 | functions | 함수와 타입 선언
## 함수 정의
- `function add(int $a, int $b): int { return $a + $b; }`
- 기본값: `function greet(string $name = "손님")`
- **이름 있는 인자 (PHP 8)**: `greet(name: "길동")`
- 가변 인자: `function sum(int ...$nums)`
- nullable 타입: `?string`, 유니온 타입: `int|float`

## strict_types
파일 맨 위에 `declare(strict_types=1);` 를 쓰면 타입 강제 변환을 막아 `add("5", 3)` 같은 호출이 TypeError가 됩니다. 현대 PHP 프로젝트의 표준입니다.

## 익명 함수와 화살표 함수
- 클로저: `function($x) use ($factor) { return $x * $factor; }` — 외부 변수는 `use` 로 가져옴
- 화살표 함수: `fn($x) => $x * $factor` — 외부 변수를 자동으로 캡처
--- code
<?php
declare(strict_types=1);

function add(int $a, int $b): int
{
    return $a + $b;
}

function greet(string $name = "방문자", string $greeting = "안녕하세요"): string
{
    return "$greeting, {$name}님!";
}

function average(float ...$nums): ?float
{
    return count($nums) ? array_sum($nums) / count($nums) : null;
}

function formatPrice(int|float $price): string
{
    return number_format($price) . "원";
}

echo add(3, 5), "\n";
echo greet(), "\n";
echo greet(greeting: "반가워요", name: "영희"), "\n";   // 이름 있는 인자
echo average(80, 90, 100), "\n";
var_dump(average());              // NULL
echo formatPrice(1234567), "\n";

$factor = 3;
$triple = fn(int $x): int => $x * $factor;            // 자동 캡처
$multiply = function (int $x) use ($factor): int {    // use로 캡처
    return $x * $factor;
};
echo $triple(5), " ", $multiply(7), "\n";

function makeCounter(): Closure
{
    $count = 0;
    return function () use (&$count): int {           // 참조로 캡처
        return ++$count;
    };
}
$counter = makeCounter();
$counter(); $counter();
echo $counter(), "\n";            // 3

try {
    echo add("5", 3);
} catch (TypeError $e) {
    echo "TypeError: strict_types 때문에 문자열 전달 불가\n";
}
--- exercise
`declare(strict_types=1)` 을 사용해 `function bmi(float $weightKg, float $heightCm): string` 을 작성하세요. BMI = 체중 / (키(m)^2) 이며, 18.5 미만 "저체중", 23 미만 "정상", 25 미만 "과체중", 그 이상 "비만"(한국 기준)을 `match(true)` 로 반환하고 BMI 값(소수 1자리)도 함께 표시합니다.
--- solution
<?php
declare(strict_types=1);

function bmi(float $weightKg, float $heightCm): string
{
    $h = $heightCm / 100;
    $value = $weightKg / ($h ** 2);
    $label = match (true) {
        $value < 18.5 => "저체중",
        $value < 23 => "정상",
        $value < 25 => "과체중",
        default => "비만",
    };
    return sprintf("BMI %.1f (%s)", $value, $label);
}

echo bmi(70, 175), "\n";   // BMI 22.9 (정상)
echo bmi(heightCm: 160, weightKg: 70), "\n";   // BMI 27.3 (비만)
--- quiz

+ 자동으로 값이 캡처된다
- use ($y) 를 반드시 써야 한다

! 일반 익명 함수(function)는 use가 필요하지만 fn은 자동 캡처합니다.
? `declare(strict_types=1);` 의 효과는?
- 모든 변수를 상수로 만든다
+ 스칼라 타입 선언에 대해 자동 형 변환을 막는다
- 경고 메시지를 숨긴다
- 실행 속도를 2배로 만든다
! 타입이 맞지 않으면 TypeError가 발생합니다.

=== 초급 | web-forms | 웹 요청과 폼 처리, 보안 기초
PHP가 웹에서 강한 이유는 HTTP 요청 정보를 **슈퍼글로벌** 변수로 바로 쓸 수 있기 때문입니다.

## 슈퍼글로벌
- `$_GET`: URL 쿼리(`?page=2`), `$_POST`: 폼 전송 데이터
- `$_SERVER`: 요청 메서드, URI 등, `$_SESSION`: 세션, `$_COOKIE`: 쿠키
- `$_FILES`: 업로드 파일

## 반드시 지켜야 할 보안 규칙
1. **출력할 때 이스케이프**: `htmlspecialchars($s, ENT_QUOTES, 'UTF-8')` → XSS 방지
2. **입력 검증**: `filter_var($email, FILTER_VALIDATE_EMAIL)`, `filter_var($n, FILTER_VALIDATE_INT)`
3. **SQL은 항상 Prepared Statement** (고급 레슨에서 다룸)
4. 비밀번호는 `password_hash()` / `password_verify()` — 절대 평문 저장 금지
5. 상태 변경 폼에는 CSRF 토큰 사용

> 아래 예제는 웹 요청 없이도 실행되도록 `$_POST` 를 직접 채워 흉내 냅니다. 실제로는 `php -S localhost:8000` 으로 서버를 띄우고 HTML 폼을 전송해 보세요.
--- code
<?php
declare(strict_types=1);

// 실제 서버에서는 브라우저가 보낸 값이 들어옵니다. 여기서는 흉내.
$_SERVER['REQUEST_METHOD'] = 'POST';
$_POST = ['name' => '<script>alert("해킹")</script>', 'email' => 'gildong@example', 'age' => '30'];

function e(string $s): string
{
    return htmlspecialchars($s, ENT_QUOTES, 'UTF-8');
}

$errors = [];
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = trim($_POST['name'] ?? '');
    $email = filter_var($_POST['email'] ?? '', FILTER_VALIDATE_EMAIL);
    $age = filter_var($_POST['age'] ?? '', FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 150]]);

    if ($name === '') $errors[] = '이름을 입력하세요';
    if ($email === false) $errors[] = '이메일 형식이 올바르지 않습니다';
    if ($age === false) $errors[] = '나이는 1~150 사이 정수여야 합니다';

    echo "<p>안녕하세요, " . e($name) . "님</p>\n";   // 스크립트가 무력화됨
    foreach ($errors as $err) {
        echo "<li>" . e($err) . "</li>\n";
    }
}

$hash = password_hash('my-secret-pw', PASSWORD_DEFAULT);
var_dump(password_verify('my-secret-pw', $hash));   // true
var_dump(password_verify('wrong', $hash));          // false

=== 고급 | pdo | PDO로 데이터베이스 다루기
**PDO(PHP Data Objects)** 는 MySQL, PostgreSQL, SQLite 등 여러 DB를 같은 API로 다루는 표준 확장입니다.

## 핵심 원칙: Prepared Statement
사용자 입력을 SQL 문자열에 직접 이어 붙이면 **SQL 인젝션** 공격에 당합니다.
- ❌ `"SELECT * FROM users WHERE name = '$name'"` — `$name` 에 `' OR '1'='1` 이 들어오면 모든 행이 노출
- ✅ `$stmt = $pdo->prepare("SELECT * FROM users WHERE name = ?"); $stmt->execute([$name]);`

## 주요 API
- 연결: `new PDO($dsn, $user, $pass, [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION])`
- `prepare` + `execute`, `fetch`, `fetchAll(PDO::FETCH_ASSOC)`, `lastInsertId()`
- 이름 있는 플레이스홀더: `:email`
- 트랜잭션: `beginTransaction()`, `commit()`, `rollBack()`

> 예제는 별도 설치 없이 돌도록 SQLite 메모리 DB를 사용합니다(pdo_sqlite 확장 필요). MySQL이라면 DSN만 `mysql:host=localhost;dbname=app;charset=utf8mb4` 로 바꾸면 됩니다.
--- code

    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    points INTEGER DEFAULT 0
)");

// 트랜잭션: 포인트 이체 (중간에 실패하면 전부 취소)
function transfer(PDO $pdo, string $from, string $to, int $amount): void
{
    $pdo->beginTransaction();
    try {
        $pdo->prepare("UPDATE users SET points = points - ? WHERE name = ?")->execute([$amount, $from]);
        $check = $pdo->prepare("SELECT points FROM users WHERE name = ?");
        $check->execute([$from]);
        if ($check->fetchColumn() < 0) {
            throw new RuntimeException("포인트 부족");
        }
        $pdo->prepare("UPDATE users SET points = points + ? WHERE name = ?")->execute([$amount, $to]);
        $pdo->commit();
        echo "이체 성공: $from → $to ($amount)\n";
    } catch (Throwable $e) {
        $pdo->rollBack();
        echo "이체 실패, 롤백: {$e->getMessage()}\n";
    }
}

transfer($pdo, '영희', '철수', 50);
transfer($pdo, '철수', '길동', 1000);
foreach ($pdo->query("SELECT name, points FROM users ORDER BY id") as $row) {
    echo "{$row['name']}={$row['points']} ";
}
echo "\n";

try {
    $insert->execute(['name' => '중복', 'email' => 'gd@ex.com', 'points' => 0]);
} catch (PDOException $e) {
    echo "UNIQUE 제약 위반 감지\n";
}

        $s = preg_replace('/\s+/', '-', $s);
        $s = preg_replace('/[^a-z0-9-]/', '', $s);
        return trim(preg_replace('/-+/', '-', $s), '-');
    }

    public static function truncate(string $text, int $len): string
    {
        return mb_strlen($text) > $len ? mb_substr($text, 0, $len) . '…' : $text;
    }
}
