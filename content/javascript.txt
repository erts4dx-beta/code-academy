=== 입문 | intro | 자바스크립트 시작하기
자바스크립트(JavaScript, JS)는 웹 페이지에 **동작**을 부여하는 언어입니다. HTML이 뼈대, CSS가 디자인이라면 JS는 클릭, 입력, 데이터 통신 같은 상호작용을 담당합니다. 이름이 비슷하지만 Java와는 전혀 다른 언어입니다.

## 실행하는 방법
- **브라우저 개발자 도구**: F12 → Console 탭에서 바로 코드를 입력
- **HTML 파일**: `<script src="app.js"></script>` 로 연결
- **Node.js**: nodejs.org 에서 설치 후 `node app.js`
- **이 사이트**: 코드 블록의 ▶ 실행 버튼 또는 플레이그라운드

`console.log()` 는 값을 콘솔에 출력합니다. 문장 끝의 세미콜론(`;`)은 대부분 생략 가능하지만, 예상치 못한 버그를 막기 위해 붙이는 스타일이 일반적입니다.
--- code
// 한 줄 주석
/* 여러 줄
   주석 */
console.log("Hello, World!");
console.log("안녕하세요,", "자바스크립트!");
console.log(1 + 2 * 3);          // 7
console.log("10" + 5);           // "105" (문자열 연결)
console.log("10" - 5);           // 5   (숫자로 변환되어 뺄셈)
console.log(typeof 42, typeof "hi", typeof true);

=== 입문 | variables | 변수: let, const와 자료형
변수 선언에는 `let`(재할당 가능)과 `const`(재할당 불가)를 사용합니다. 오래된 `var` 는 함수 스코프와 호이스팅 문제 때문에 **현대 코드에서는 쓰지 않는 것**이 좋습니다.

> 기본은 `const`, 값을 바꿔야 할 때만 `let` 을 쓰세요. 단, `const` 로 선언한 객체/배열의 **내용**은 바꿀 수 있습니다(참조만 고정).

## 원시 자료형 (7가지)
- `number`: 정수와 실수 구분 없음 (`42`, `3.14`, `NaN`, `Infinity`)
- `string`: 문자열. 백틱(`)을 쓰는 **템플릿 리터럴**에서 `${}` 로 값 삽입
- `boolean`: `true` / `false`
- `undefined`: 값이 할당되지 않음
- `null`: 의도적으로 "값 없음"
- `bigint`, `symbol`

## 동등 비교
`==` 는 형 변환 후 비교(`"5" == 5` → true)하므로 혼란스럽습니다. **항상 `===` 를 사용**하세요.
--- code
const name = "길동";
let age = 30;
age = age + 1;

console.log(`${name}님은 ${age}살입니다.`);

const user = { name: "영희" };
user.name = "철수";       // OK: 내용 변경
// user = {};             // TypeError: 재할당 불가
console.log(user);

console.log(0.1 + 0.2);            // 0.30000000000000004 (부동소수점)
console.log((0.1 + 0.2).toFixed(2)); // "0.30"
console.log(Number("42"), parseInt("42px"), Number("abc"));  // 42 42 NaN

console.log("5" == 5, "5" === 5);  // true false
console.log(null == undefined, null === undefined);  // true false
console.log(typeof null);          // "object" (언어 초기의 유명한 버그)

=== 입문 | operators | 연산자와 조건문
## 조건문
`if / else if / else` 와 `switch` 로 분기합니다. 간단한 경우 삼항 연산자 `조건 ? A : B` 를 씁니다.

## 논리 연산자와 단락 평가
- `&&`: 왼쪽이 falsy면 왼쪽 값, 아니면 오른쪽 값
- `||`: 왼쪽이 truthy면 왼쪽 값, 아니면 오른쪽 값
- `??` (널 병합): 왼쪽이 `null` / `undefined` 일 때만 오른쪽 값
- `?.` (옵셔널 체이닝): 중간 값이 null/undefined면 오류 대신 `undefined`

Falsy 값은 `false, 0, -0, 0n, "", null, undefined, NaN` 이고, 나머지는 모두 truthy입니다(`"0"`, `[]`, `{}` 도 truthy!).

> `count || 10` 은 count가 `0` 일 때도 10이 됩니다. 0을 유효한 값으로 쓰려면 `count ?? 10` 을 사용하세요.
--- code
const score = 78;
if (score >= 90) console.log("A");
else if (score >= 80) console.log("B");
else console.log("C 이하");

const day = "토";
switch (day) {
  case "토":
  case "일":
    console.log("주말");
    break;
  default:
    console.log("평일");
}

const count = 0;
console.log(count || 10);   // 10
console.log(count ?? 10);   // 0

const user = { profile: null };
console.log(user.profile?.email);          // undefined (오류 없음)
console.log(user.profile?.email ?? "없음"); // "없음"

const isMember = true;
console.log(`가격: ${isMember ? 9000 : 10000}원`);
--- exercise
변수 `hour`(0~23)에 따라 6~11시는 "아침", 12~17시는 "오후", 18~21시는 "저녁", 그 외는 "밤"을 출력하는 코드를 작성하세요. `hour` 가 `undefined` 이면 `??` 를 이용해 기본값 `12` 를 사용하세요.
--- solution
let input; // undefined
const hour = input ?? 12;
let label;
if (hour >= 6 && hour <= 11) label = "아침";
else if (hour >= 12 && hour <= 17) label = "오후";
else if (hour >= 18 && hour <= 21) label = "저녁";
else label = "밤";
console.log(hour, label);   // 12 오후
--- quiz

=== 초급 | loops | 반복문
## 종류
- `for (let i = 0; i < n; i++)`: 고전적인 카운터 반복
- `for...of`: 배열, 문자열, Map, Set 등 **이터러블의 값**을 순회 (가장 추천)
- `for...in`: 객체의 **키(속성 이름)** 를 순회. 배열에는 쓰지 마세요
- `while`, `do...while`: 조건 기반 반복 (do...while은 최소 1회 실행)

`break` 로 중단, `continue` 로 건너뛸 수 있습니다. 객체를 순회할 때는 `Object.entries(obj)` 와 `for...of` 조합이 편리합니다.
--- code
for (let i = 1; i <= 3; i++) {
  console.log(`${i}번째`);
}

const fruits = ["사과", "바나나", "포도"];
for (const f of fruits) console.log(f);

for (const [i, f] of fruits.entries()) {
  console.log(i, f);
}

const scores = { 철수: 90, 영희: 85 };
for (const key in scores) console.log(key, scores[key]);
for (const [name, s] of Object.entries(scores)) console.log(`${name}: ${s}`);

let n = 0;
while (true) {
  n++;
  if (n % 2 === 0) continue;
  if (n > 7) break;
  console.log("홀수", n);
}
--- exercise
1부터 50까지 반복하면서 3의 배수는 "Fizz", 5의 배수는 "Buzz", 15의 배수는 "FizzBuzz", 나머지는 숫자를 배열에 담아 마지막에 한 번에 출력하세요. (FizzBuzz 문제)
--- solution
const out = [];
for (let i = 1; i <= 50; i++) {
  if (i % 15 === 0) out.push("FizzBuzz");
  else if (i % 3 === 0) out.push("Fizz");
  else if (i % 5 === 0) out.push("Buzz");
  else out.push(i);
}
console.log(out.join(", "));

=== 초급 | functions | 함수와 화살표 함수
## 함수를 만드는 세 가지 방법
- 함수 선언문: `function add(a, b) { return a + b; }` — **호이스팅**되어 선언 전에 호출 가능
- 함수 표현식: `const add = function (a, b) { ... };`
- 화살표 함수: `const add = (a, b) => a + b;` — 본문이 식 하나면 중괄호와 return 생략

## 매개변수 기능
- 기본값: `function greet(name = "손님")`
- 나머지 매개변수: `function sum(...nums)` → 배열로 받음
- 구조 분해: `function draw({ x, y })`

## 일급 함수와 클로저
함수는 값이므로 다른 함수에 넘기거나(콜백) 반환할 수 있습니다. 함수가 만들어질 때의 바깥 변수를 기억하는 것을 **클로저**라고 합니다.

> 화살표 함수는 자신만의 `this` 를 갖지 않고 바깥의 `this` 를 그대로 사용합니다. 객체 메서드로는 일반 함수를 쓰는 것이 안전합니다.
--- code
function add(a, b) {
  return a + b;
}
const square = x => x * x;
const greet = (name = "손님") => `안녕하세요, ${name}님`;

console.log(add(2, 3), square(4), greet(), greet("길동"));

function sum(...nums) {
  return nums.reduce((acc, n) => acc + n, 0);
}
console.log(sum(1, 2, 3, 4));   // 10

// 콜백
function repeat(n, fn) {
  for (let i = 0; i < n; i++) fn(i);
}
repeat(3, i => console.log("반복", i));

// 클로저: 외부에서 직접 접근할 수 없는 상태
function makeCounter() {
  let count = 0;
  return {
    inc: () => ++count,
    get: () => count,
  };
}
const c = makeCounter();
c.inc(); c.inc();
console.log(c.get());   // 2
--- exercise
숫자 `n` 을 받아 "n을 곱하는 함수"를 반환하는 `multiplier(n)` 을 화살표 함수로 작성하세요. `const double = multiplier(2)`, `const triple = multiplier(3)` 을 만들어 `double(5)`, `triple(5)` 를 출력하세요.
--- solution
const multiplier = n => x => x * n;
const double = multiplier(2);
const triple = multiplier(3);
console.log(double(5), triple(5));   // 10 15

=== 초급 | arrays | 배열과 고차 함수
배열은 순서가 있는 값의 목록입니다. 자바스크립트 배열은 다양한 **고차 함수**(함수를 인자로 받는 메서드)를 제공해 반복문 없이 데이터를 변환할 수 있습니다.

## 필수 메서드
- `map(fn)`: 각 원소를 변환한 **새 배열**
- `filter(fn)`: 조건을 만족하는 원소만 모은 새 배열
- `reduce(fn, 초기값)`: 하나의 값으로 누적
- `find(fn)` / `findIndex(fn)`: 첫 번째로 일치하는 원소 / 인덱스
- `some(fn)` / `every(fn)`: 하나라도 / 모두 만족하는지
- `sort(비교함수)`: **원본을 변경**함. 숫자 정렬은 `(a, b) => a - b` 필수
- `includes`, `slice`, `splice`, `concat`, `flat`, `join`

## 전개 연산자와 구조 분해
`[...a, ...b]` 로 배열을 합치거나 복사하고, `const [first, ...rest] = arr` 로 나눠 받습니다.

> `[10, 1, 2].sort()` 는 `[1, 10, 2]` 가 됩니다. 기본 정렬은 **문자열 기준**이기 때문입니다.
--- code
const products = [
  { name: "노트북", price: 1500000, category: "전자" },
  { name: "마우스", price: 30000, category: "전자" },
  { name: "의자", price: 250000, category: "가구" },
  { name: "책상", price: 400000, category: "가구" },
];

const names = products.map(p => p.name);
const cheap = products.filter(p => p.price < 300000);
const total = products.reduce((sum, p) => sum + p.price, 0);
console.log(names);
console.log(cheap.map(p => p.name));
console.log(total.toLocaleString() + "원");

console.log(products.find(p => p.category === "가구").name);  // 의자
console.log(products.some(p => p.price > 1000000));           // true

const sorted = [...products].sort((a, b) => b.price - a.price); // 원본 보존
console.log(sorted.map(p => `${p.name}(${p.price})`).join(" > "));

// 카테고리별 그룹화
const byCat = products.reduce((acc, p) => {
  (acc[p.category] ??= []).push(p.name);
  return acc;
}, {});
console.log(byCat);

const [first, ...rest] = [1, 2, 3, 4];
console.log(first, rest, [10, 1, 2].sort(), [10, 1, 2].sort((a, b) => a - b));
--- exercise
`const words = ["apple", "Banana", "cherry", "date", "Elderberry", "fig"]` 에서 길이가 5 이상인 단어만 골라 모두 소문자로 바꾸고, 알파벳 순으로 정렬한 배열을 메서드 체이닝 한 줄로 만들어 출력하세요. 또 전체 글자 수의 합을 reduce로 구하세요.
--- solution
const words = ["apple", "Banana", "cherry", "date", "Elderberry", "fig"];
const result = words
  .filter(w => w.length >= 5)
  .map(w => w.toLowerCase())
  .sort();
console.log(result);   // ['apple', 'banana', 'cherry', 'elderberry']
console.log(words.reduce((n, w) => n + w.length, 0));   // 34

class Shape {
  static count = 0;
  #id;

  constructor(name) {
    this.name = name;
    this.#id = ++Shape.count;
  }
  area() {
    return 0;
  }
  toString() {
    return `#${this.#id} ${this.name} (넓이 ${this.area().toFixed(2)})`;
  }
}

class Circle extends Shape {
  constructor(r) {
    super("원");
    this.r = r;
  }
  area() {
    return Math.PI * this.r ** 2;

}

  constructor(w, h) {
    super("사각형");
    this.w = w;
    this.h = h;
  }
  area() {
    return this.w * this.h;
  }
  get isSquare() {
    return this.w === this.h;
  }
}

=== 중급 | async | 비동기: Promise와 async/await
자바스크립트는 **싱글 스레드**지만, 네트워크 요청이나 타이머 같은 작업을 기다리는 동안 멈추지 않도록 **이벤트 루프** 기반 비동기 모델을 사용합니다.

## 발전 과정
1. 콜백: 중첩이 깊어지는 "콜백 지옥" 문제
2. **Promise**: 미래의 결과를 나타내는 객체. `then` / `catch` 로 연결
3. **async/await**: Promise를 동기 코드처럼 읽기 쉽게 작성

## Promise 조합
- `Promise.all([...])`: 모두 성공해야 성공 (하나라도 실패하면 즉시 실패)
- `Promise.allSettled`: 성공/실패와 관계없이 모든 결과
- `Promise.race`: 가장 먼저 끝난 것
- `Promise.any`: 가장 먼저 **성공**한 것

> `await` 를 반복문 안에서 하나씩 쓰면 순차 실행이 됩니다. 서로 독립적인 작업은 `Promise.all` 로 동시에 실행하세요.
--- code
const delay = (ms, value, fail = false) =>
  new Promise((resolve, reject) =>
    setTimeout(() => (fail ? reject(new Error(value)) : resolve(value)), ms)
  );

// then 체이닝
delay(100, "첫 번째")
  .then(v => { console.log(v); return delay(100, "두 번째"); })
  .then(v => console.log(v));

// async/await
async function main() {
  const [a, b] = await Promise.all([delay(300, "A"), delay(200, "B")]);
  console.log("동시 실행 결과:", a, b);   // 약 300ms

  try {
    await delay(50, "서버 오류", true);
  } catch (e) {
    console.log("잡은 오류:", e.message);
  }

  const results = await Promise.allSettled([delay(10, "ok"), delay(10, "fail", true)]);
  console.log(results.map(r => r.status));  // ['fulfilled', 'rejected']
}
await main();

// 실행 순서 퀴즈
console.log("1");
setTimeout(() => console.log("4 (매크로태스크)"), 0);
Promise.resolve().then(() => console.log("3 (마이크로태스크)"));
console.log("2");

=== 고급 | dom | DOM 조작과 이벤트
브라우저는 HTML 문서를 **DOM(Document Object Model)** 이라는 트리 구조 객체로 만들고, 자바스크립트는 이 DOM을 통해 페이지를 읽고 바꿉니다.

## 핵심 API
- 선택: `document.querySelector(css선택자)`, `querySelectorAll`
- 내용: `textContent`(텍스트), `innerHTML`(HTML — 사용자 입력에 쓰면 XSS 위험)
- 속성/스타일: `el.classList.add/remove/toggle`, `el.dataset`, `el.style`
- 생성: `document.createElement`, `append`, `remove`
- 이벤트: `el.addEventListener("click", handler)`

## 이벤트 위임
목록의 항목마다 리스너를 다는 대신 **부모 하나에 리스너를 달고** `event.target.closest()` 로 어떤 항목인지 판단합니다. 동적으로 추가되는 요소도 자동으로 처리되고 메모리도 아낄 수 있습니다.

> 아래 예제는 HTML 파일에서 실행하는 코드입니다. `<script>` 를 `</body>` 직전에 두거나 `defer` 속성을 쓰면 DOM이 준비된 뒤 실행됩니다.
--- code html
<!DOCTYPE html>
<html lang="ko">
<body>
  <input id="todoInput" placeholder="할 일 입력">
  <button id="addBtn">추가</button>
  <ul id="list"></ul>

  <script>
    const input = document.querySelector("#todoInput");
    const list = document.querySelector("#list");

    function addTodo() {
      const text = input.value.trim();
      if (!text) return;
      const li = document.createElement("li");
      li.textContent = text;            // innerHTML 대신 textContent: XSS 방지
      const del = document.createElement("button");
      del.textContent = "삭제";
      del.dataset.action = "delete";
      li.append(" ", del);
      list.append(li);
      input.value = "";
      input.focus();
    }

    document.querySelector("#addBtn").addEventListener("click", addTodo);
    input.addEventListener("keydown", e => { if (e.key === "Enter") addTodo(); });

    // 이벤트 위임: ul 하나에만 리스너
    list.addEventListener("click", e => {
      const li = e.target.closest("li");
      if (!li) return;
      if (e.target.dataset.action === "delete") li.remove();
      else li.classList.toggle("done");
    });
  </script>
  <style>.done { text-decoration: line-through; color: gray; }</style>
</body>
</html>

## 이터레이션 프로토콜
`[Symbol.iterator]()` 메서드를 구현하면 `for...of`, 전개 연산자에서 쓸 수 있는 객체가 됩니다. `function*` 와 `yield` 로 만드는 **제너레이터**를 쓰면 간단히 구현할 수 있습니다.

## Map과 Set
- `Map`: 어떤 값이든 키로 쓸 수 있고 삽입 순서를 유지하는 키-값 저장소
- `Set`: 중복 없는 값의 집합. `[...new Set(arr)]` 로 중복 제거
--- code
// math.js (모듈 예시 — 실제로는 별도 파일)
// export const PI = 3.14159;
// export default function area(r) { return PI * r * r; }
// main.js
// import area, { PI } from "./math.js";

class Range {
  constructor(start, end, step = 1) {
    Object.assign(this, { start, end, step });
  }
  *[Symbol.iterator]() {
    for (let v = this.start; v < this.end; v += this.step) yield v;
  }
}
console.log([...new Range(0, 10, 3)]);   // [0, 3, 6, 9]

function* idGenerator(prefix) {
  let i = 1;
  while (true) yield `${prefix}-${String(i++).padStart(3, "0")}`;
}
const ids = idGenerator("ORD");
console.log(ids.next().value, ids.next().value);   // ORD-001 ORD-002

const visits = new Map();

  visits.set(page, (visits.get(page) ?? 0) + 1);
}
console.log(visits, visits.get("/"));
console.log([...new Set([3, 1, 3, 2, 1])]);   // [3, 1, 2]

function* chunk(arr, size) {
  for (let i = 0; i < arr.length; i += size) {
    yield arr.slice(i, i + size);
  }
}
console.log([...chunk([1, 2, 3, 4, 5, 6, 7], 3)]);

=== 고급 | errors-patterns | 에러 처리와 실전 패턴
## 에러 처리
- `try / catch / finally` 로 동기 코드와 `await` 의 에러를 처리
- `throw new Error("메시지")` — 문자열 대신 Error 객체를 던져야 스택 정보가 남음
- 커스텀 에러: `class ValidationError extends Error`
- `Error` 의 `cause` 옵션으로 원인 에러를 연결: `new Error("저장 실패", { cause: e })`

## 실전 유틸리티 패턴
- **디바운스(debounce)**: 입력이 멈춘 뒤 일정 시간이 지나야 실행 (검색창 자동완성)
- **스로틀(throttle)**: 일정 시간에 최대 한 번만 실행 (스크롤 이벤트)
- **메모이제이션**: 같은 입력의 결과를 캐시

> 이 사이트의 검색창 역시 입력할 때마다 결과를 갱신합니다. 데이터가 크다면 디바운스를 적용하는 것이 좋습니다.
--- code
class ValidationError extends Error {
  constructor(field, message) {
    super(message);
    this.name = "ValidationError";
    this.field = field;
  }
}

function validateUser(u) {
  if (!u.email?.includes("@")) throw new ValidationError("email", "이메일 형식 오류");
  if (u.age < 0) throw new ValidationError("age", "나이는 0 이상");
  return true;
}

try {
  validateUser({ email: "wrong", age: 20 });
} catch (e) {
  if (e instanceof ValidationError) console.log(`[${e.field}] ${e.message}`);
  else throw e;   // 모르는 에러는 다시 던진다
}

function debounce(fn, ms) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}
const search = debounce(q => console.log("검색 실행:", q), 200);
search("j"); search("ja"); search("jav"); search("java");  // 마지막 한 번만 실행

function memoize(fn) {
  const cache = new Map();
  return n => cache.has(n) ? cache.get(n) : (cache.set(n, fn(n)), cache.get(n));
}
const slowSquare = n => { for (let i = 0; i < 1e6; i++); return n * n; };
const fast = memoize(slowSquare);
console.log(fast(9), fast(9));   // 두 번째는 캐시
await new Promise(r => setTimeout(r, 300));
--- exercise
지정한 밀리초마다 최대 한 번만 함수를 실행하는 `throttle(fn, ms)` 를 작성하세요. 50ms 간격으로 10번 호출했을 때 200ms 스로틀이면 몇 번 실행되는지 확인해 보세요.
--- solution
function throttle(fn, ms) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= ms) {
      last = now;
      fn(...args);
    }
  };
}
let runs = 0;
const t = throttle(() => runs++, 200);
for (let i = 0; i < 10; i++) {
  setTimeout(t, i * 50);
}
await new Promise(r => setTimeout(r, 600));
console.log("실행 횟수:", runs);   // 약 3회 (0ms, 200ms, 400ms 부근)
