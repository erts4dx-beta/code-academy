=== 입문 | hello | Go 시작하기
Go(Golang)는 2009년 구글의 롭 파이크, 켄 톰프슨 등이 만든 언어입니다. **단순함**을 최우선으로 설계되어 키워드가 25개뿐이며, 빠른 컴파일, 단일 실행 파일 배포, 강력한 표준 라이브러리가 특징입니다. Docker, Kubernetes, Terraform이 Go로 만들어졌습니다.

## 시작하기
1. go.dev 에서 설치 → `go version` 확인
2. `go mod init example.com/hello` 로 모듈 생성
3. `go run main.go` 로 바로 실행, `go build` 로 실행 파일 생성
4. `gofmt` 가 코드 스타일을 자동 통일 — 스타일 논쟁이 없습니다.

## 구조
- 모든 파일은 `package` 선언으로 시작. 실행 프로그램은 `package main` + `func main()`
- `import "fmt"` 로 패키지 사용. **사용하지 않는 import나 변수는 컴파일 오류**입니다.
- 이름이 **대문자로 시작하면 외부 공개(exported)**, 소문자면 패키지 내부 전용
--- code
package main

import (
	"fmt"
	"strings"
)

func main() {
	fmt.Println("Hello, World!")
	fmt.Println("안녕하세요,", "Go!")

	name := "길동"
	fmt.Printf("%s님, Go는 %d년에 공개되었습니다.\n", name, 2009)
	fmt.Println(strings.ToUpper("gopher"), strings.Repeat("=", 10))

	msg := fmt.Sprintf("%v / %T", 3.14, 3.14) // 값과 타입
	fmt.Println(msg)                          // 3.14 / float64
}

}

=== 입문 | variables | 변수, 타입, 상수
## 변수 선언
- `var name string = "길동"` — 전체 형식
- `var age = 30` — 타입 추론
- `count := 0` — **짧은 선언**(함수 안에서만). 가장 많이 사용
- 초기화하지 않으면 **제로 값**: 숫자 `0`, 문자열 `""`, bool `false`, 포인터/슬라이스/맵 `nil`

## 기본 타입
`int`, `int64`, `uint8`(=`byte`), `float64`, `string`, `bool`, `rune`(유니코드 문자, `int32`)

## 형 변환
Go는 **암시적 형 변환이 없습니다**. `int` 와 `float64` 를 바로 더할 수 없고 `float64(i)` 처럼 명시해야 합니다. 문자열↔숫자는 `strconv` 패키지(`strconv.Itoa`, `strconv.Atoi`)를 씁니다.

## 상수
`const Pi = 3.14159`, `iota` 로 연속 상수(열거형)를 만듭니다.
--- code
package main

import (
	"fmt"
	"strconv"
)

type Weekday int

const (
	Sunday Weekday = iota // 0
	Monday                // 1
	Tuesday               // 2
)

func main() {
	var name string = "길동"
	var age = 30
	height := 175.5
	var zero int
	var empty string

	fmt.Println(name, age, height, zero, empty == "")

	total := float64(age) + height // 명시적 변환 필수
	fmt.Println(total)

	s := strconv.Itoa(age) + "살"
	n, err := strconv.Atoi("42")
	if err == nil {
		fmt.Println(s, n+1)
	}

	word := "Go언어"
	fmt.Println(len(word))         // 8 (바이트 수: 한글은 3바이트씩)
	fmt.Println(len([]rune(word))) // 4 (문자 수)
	for i, r := range word {
		fmt.Printf("%d:%c ", i, r)
	}
	fmt.Println()
	fmt.Println(Monday, Tuesday)
}

=== 입문 | control | 조건문, 반복문, switch
## if
조건에 괄호가 없고, 중괄호는 필수입니다. **초기화 문**을 함께 쓸 수 있습니다: `if v, err := f(); err != nil { ... }`

## for — Go의 유일한 반복문
- `for i := 0; i < 10; i++ { }` — 전통적 형태
- `for 조건 { }` — while처럼
- `for { }` — 무한 루프
- `for i, v := range 슬라이스 { }` — 순회 (인덱스가 필요 없으면 `_`)
- Go 1.22+: `for i := range 10 { }` — 0부터 9까지

## switch
`break` 가 필요 없습니다(자동으로 빠져나옴). 여러 값 `case "a", "b":`, 조건 없는 switch(`switch { case x > 0: ... }`)로 if-else 체인을 대체할 수 있습니다. 다음 case로 넘어가려면 `fallthrough`.
--- code
package main

import "fmt"

func main() {
	score := 85
	if score >= 90 {
		fmt.Println("A")
	} else if score >= 80 {
		fmt.Println("B")
	} else {
		fmt.Println("C")
	}

	for i := 1; i <= 3; i++ {
		fmt.Print(i, " ")
	}
	fmt.Println()

	n := 1
	for n < 100 {
		n *= 3
	}
	fmt.Println("100을 넘는 3의 거듭제곱:", n) // 243

	fruits := []string{"사과", "바나나", "포도"}
	for i, f := range fruits {
		fmt.Println(i, f)
	}

	for i := range 3 { // Go 1.22+
		fmt.Print(i, " ")
	}
	fmt.Println()

	day := "토"
	switch day {
	case "토", "일":
		fmt.Println("주말")
	default:
		fmt.Println("평일")
	}

	temp := 28
	switch {
	case temp >= 30:
		fmt.Println("더움")
	case temp >= 20:
		fmt.Println("따뜻함")
	default:
		fmt.Println("쌀쌀함")
	}
}

=== 초급 | functions | 함수, 다중 반환, 에러 처리
## 함수
`func add(a, b int) int { return a + b }` — 같은 타입 매개변수는 묶어서 씁니다.
- **다중 반환**: `func divmod(a, b int) (int, int)`
- 이름 있는 반환값: `func f() (result int, err error)`
- 가변 인자: `func sum(nums ...int) int`
- 함수는 일급 값: 변수에 담고, 인자로 넘기고, 클로저를 만들 수 있음

## 에러 처리
Go에는 예외(try/catch)가 없습니다. 대신 **에러를 마지막 반환값**으로 돌려주고, 호출한 쪽에서 `if err != nil` 로 확인합니다. 명시적이라 에러 흐름이 코드에 그대로 드러납니다.
- `errors.New("메시지")`, `fmt.Errorf("문맥: %w", err)` — `%w` 로 원인 에러를 감쌈
- `errors.Is`, `errors.As` 로 감싼 에러 검사

## defer
`defer` 는 함수가 끝날 때 실행할 작업을 예약합니다(파일 닫기, 잠금 해제). 여러 개면 **역순(LIFO)** 으로 실행됩니다.
--- code
package main

import (
	"errors"
	"fmt"
)

var ErrDivideByZero = errors.New("0으로 나눌 수 없음")

func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, ErrDivideByZero
	}
	return a / b, nil
}

func sum(nums ...int) (total int) {
	for _, n := range nums {
		total += n
	}
	return // 이름 있는 반환값 total 반환
}

func makeCounter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}

func loadConfig(path string) error {
	_, err := divide(1, 0)
	if err != nil {
		return fmt.Errorf("설정 %s 로드 실패: %w", path, err)
	}
	return nil
}

func main() {
	if r, err := divide(10, 4); err == nil {
		fmt.Println(r) // 2.5
	}

	err := loadConfig("app.yaml")
	fmt.Println(err)
	fmt.Println(errors.Is(err, ErrDivideByZero)) // true (감싼 에러도 검사)

	fmt.Println(sum(1, 2, 3), sum())
	nums := []int{4, 5}
	fmt.Println(sum(nums...)) // 슬라이스 펼치기

	next := makeCounter()
	next()
	fmt.Println(next()) // 2

	defer fmt.Println("defer 1 (마지막에 실행)")
	defer fmt.Println("defer 2")
	fmt.Println("main 본문 끝")
}
--- exercise
문자열을 받아 정수로 변환하되, 음수이면 에러를 반환하는 `func parsePositive(s string) (int, error)` 를 작성하세요. `strconv.Atoi` 의 에러는 `fmt.Errorf` 와 `%w` 로 감싸고, `"42"`, `"-3"`, `"abc"` 로 테스트하세요.
--- solution
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func parsePositive(s string) (int, error) {
	n, err := strconv.Atoi(s)
	if err != nil {
		return 0, fmt.Errorf("%q 변환 실패: %w", s, err)
	}
	if n < 0 {
		return 0, errors.New("음수는 허용되지 않습니다")
	}
	return n, nil
}

func main() {
	for _, s := range []string{"42", "-3", "abc"} {
		n, err := parsePositive(s)
		if err != nil {
			fmt.Println("에러:", err)
			continue
		}
		fmt.Println("성공:", n)
	}
}

=== 초급 | slices-maps | 배열, 슬라이스, 맵
## 배열 vs 슬라이스
- 배열 `[3]int` 은 **크기가 타입의 일부**인 고정 길이. 잘 쓰지 않음
- **슬라이스** `[]int` 는 배열의 일부를 가리키는 가변 길이 뷰. 실무에서는 거의 슬라이스를 씀
- `append(s, v)` 로 추가 — **반드시 결과를 다시 대입**: `s = append(s, v)`
- `len(s)` 길이, `cap(s)` 용량, `make([]int, 0, 10)` 으로 용량 미리 확보
- `s[1:3]` 슬라이싱은 **같은 배열을 공유**합니다. 독립 복사본은 `copy` 또는 `slices.Clone`

## 맵
`map[string]int` — 해시 맵. `make(map[string]int)` 또는 리터럴로 생성.
- 조회: `v, ok := m["key"]` — ok로 존재 여부 확인 (comma ok 관용구)
- 삭제: `delete(m, "key")`
- **순회 순서는 무작위**입니다. 정렬이 필요하면 키를 슬라이스로 모아 정렬하세요.
- `slices`, `maps` 표준 패키지(Go 1.21+)가 정렬, 검색 등 유틸리티를 제공합니다.
--- code
package main

import (
	"fmt"
	"maps"
	"slices"
	"strings"
)

func main() {
	nums := []int{5, 2, 8}
	nums = append(nums, 1, 9)
	fmt.Println(nums, len(nums), cap(nums) >= len(nums))

	sub := nums[1:3] // [2 8]
	sub[0] = 100     // 원본도 바뀜!
	fmt.Println(nums)

	clone := slices.Clone(nums)
	slices.Sort(clone)
	fmt.Println(clone, slices.Contains(clone, 9), slices.Index(clone, 8))

	matrix := [][]int{{1, 2}, {3, 4}}
	fmt.Println(matrix[1][0]) // 3

	ages := map[string]int{"철수": 25, "영희": 31}
	ages["길동"] = 30
	if age, ok := ages["민수"]; !ok {
		fmt.Println("민수 없음", age) // age는 제로 값 0
	}
	delete(ages, "철수")

	keys := slices.Sorted(maps.Keys(ages)) // 정렬된 키 (Go 1.23+)
	for _, k := range keys {
		fmt.Println(k, ages[k])
	}

	counts := make(map[string]int)
	for _, w := range strings.Fields("go is fun go is fast go") {
		counts[w]++
	}
	fmt.Println(counts["go"], counts["is"]) // 3 2
}
--- exercise
정수 슬라이스를 받아 중복을 제거하되 **처음 등장한 순서를 유지**한 새 슬라이스를 반환하는 `func unique(nums []int) []int` 를 맵을 이용해 작성하세요. `[]int{3, 1, 3, 2, 1, 5}` → `[3 1 2 5]`.
--- solution
package main

import "fmt"

func unique(nums []int) []int {
	seen := make(map[int]bool)
	result := make([]int, 0, len(nums))
	for _, n := range nums {
		if !seen[n] {
			seen[n] = true
			result = append(result, n)
		}
	}
	return result
}

func main() {
	fmt.Println(unique([]int{3, 1, 3, 2, 1, 5})) // [3 1 2 5]
}

! 용량이 부족하면 새 배열이 할당되므로 반환된 슬라이스를 다시 받아야 합니다.

=== 초급 | structs | 구조체와 메서드
Go에는 클래스가 없습니다. 대신 **구조체(struct)** 에 **메서드**를 붙입니다.

## 메서드와 리시버
`func (p Person) Greet() string` — `p` 가 리시버입니다.
- **값 리시버** `(p Person)`: 복사본으로 동작. 읽기 전용 메서드에 적합
- **포인터 리시버** `(p *Person)`: 원본을 수정. 구조체가 크거나 상태를 바꿀 때 사용
- 한 타입의 메서드는 리시버 종류를 일관되게 맞추는 것이 관례입니다.

## 생성자 함수
Go에는 생성자가 없으므로 `NewPerson(...) *Person` 같은 함수를 관례적으로 만듭니다.

## 임베딩 (상속 대신 조합)
구조체 안에 다른 구조체를 이름 없이 넣으면, 그 필드와 메서드를 바로 사용할 수 있습니다. Go는 상속이 아닌 **조합(composition)** 을 지향합니다.
--- code
package main

import "fmt"

type Account struct {
	Owner   string
	balance int // 소문자: 패키지 외부에서 접근 불가
}

func NewAccount(owner string, initial int) *Account {
	return &Account{Owner: owner, balance: initial}
}

func (a *Account) Deposit(amount int) { // 포인터 리시버: 상태 변경
	a.balance += amount
}

func (a *Account) Withdraw(amount int) error {
	if amount > a.balance {
		return fmt.Errorf("잔액 부족: %d원 부족", amount-a.balance)
	}
	a.balance -= amount
	return nil
}

func (a Account) String() string { // fmt.Stringer 인터페이스 구현
	return fmt.Sprintf("%s: %d원", a.Owner, a.balance)
}

type Animal struct{ Name string }

func (a Animal) Describe() string { return "나는 " + a.Name }

type Dog struct {
	Animal // 임베딩
	Breed  string
}

func main() {
	acc := NewAccount("길동", 10000)
	acc.Deposit(5000)
	if err := acc.Withdraw(50000); err != nil {
		fmt.Println(err)
	}
	fmt.Println(acc) // String() 메서드가 자동 사용됨

	d := Dog{Animal: Animal{Name: "바둑이"}, Breed: "진돗개"}
	fmt.Println(d.Describe(), d.Name, d.Breed) // 임베딩된 메서드/필드 사용

	p := struct{ X, Y int }{1, 2} // 익명 구조체
	fmt.Printf("%+v\n", p)        // {X:1 Y:2}
}

=== 중급 | interfaces | 인터페이스와 제네릭
## 인터페이스
메서드 집합을 정의한 타입입니다. Go의 인터페이스는 **암시적으로 구현**됩니다. `implements` 선언 없이, 메서드만 갖추면 자동으로 그 인터페이스를 만족합니다.
- 작은 인터페이스가 Go의 철학: `io.Reader`(Read 하나), `fmt.Stringer`(String 하나), `error`(Error 하나)
- `any`(= `interface{}`)는 모든 타입을 담음
- 타입 단언 `v, ok := x.(string)`, 타입 스위치 `switch v := x.(type)`

## 제네릭 (Go 1.18+)
`func Map[T, U any](s []T, f func(T) U) []U` 처럼 타입 매개변수를 사용합니다. 제약은 인터페이스로 표현하며, `comparable`, `cmp.Ordered` 등 내장 제약이 있습니다.
--- code
package main

import (
	"cmp"
	"fmt"
	"math"
)

type Shape interface {
	Area() float64
	Perimeter() float64
}

type Circle struct{ R float64 }
type Rect struct{ W, H float64 }

func (c Circle) Area() float64      { return math.Pi * c.R * c.R }
func (c Circle) Perimeter() float64 { return 2 * math.Pi * c.R }
func (r Rect) Area() float64        { return r.W * r.H }
func (r Rect) Perimeter() float64   { return 2 * (r.W + r.H) }

func describe(x any) string {
	switch v := x.(type) {
	case int:
		return fmt.Sprintf("정수 %d", v)
	case string:
		return fmt.Sprintf("문자열 %q", v)
	case Shape:
		return fmt.Sprintf("도형(넓이 %.2f)", v.Area())
	default:
		return fmt.Sprintf("기타 %T", v)
	}
}

func Map[T, U any](s []T, f func(T) U) []U {
	out := make([]U, 0, len(s))
	for _, v := range s {
		out = append(out, f(v))
	}
	return out
}

func MaxOf[T cmp.Ordered](values ...T) T {
	m := values[0]
	for _, v := range values[1:] {
		m = max(m, v) // 내장 max (Go 1.21+)
	}
	return m
}

func main() {
	shapes := []Shape{Circle{1}, Rect{2, 3}} // 암시적 구현
	total := 0.0
	for _, s := range shapes {
		total += s.Area()
	}
	fmt.Printf("총 넓이: %.2f\n", total)

	for _, x := range []any{42, "go", Rect{1, 1}, 3.5} {
		fmt.Println(describe(x))
	}

	squares := Map([]int{1, 2, 3}, func(n int) int { return n * n })
	labels := Map(squares, func(n int) string { return fmt.Sprint("#", n) })
	fmt.Println(squares, labels)
	fmt.Println(MaxOf(3, 9, 4), MaxOf("kiwi", "apple"))
}

package main

import "fmt"

func Filter[T any](s []T, keep func(T) bool) []T {
	var out []T
	for _, v := range s {
		if keep(v) {
			out = append(out, v)
		}
	}
	return out
}

func main() {
	fmt.Println(Filter([]int{1, 2, 3, 4, 5, 6}, func(n int) bool { return n%2 == 0 }))
	fmt.Println(Filter([]string{"go", "rust", "java", "c"}, func(s string) bool { return len(s) >= 4 }))
	// [2 4 6] / [rust java]
}

=== 중급 | goroutines | 고루틴과 채널
Go의 가장 큰 무기는 **동시성**입니다.

## 고루틴
함수 호출 앞에 `go` 를 붙이면 **고루틴**(경량 스레드)으로 실행됩니다. 수 KB의 스택으로 시작해 수십만 개도 거뜬히 만들 수 있습니다. 런타임 스케줄러가 OS 스레드에 자동 분배합니다.

## 채널
고루틴 사이에 값을 주고받는 통로입니다. Go의 철학: **"메모리를 공유해서 통신하지 말고, 통신해서 메모리를 공유하라."**
- `ch := make(chan int)` — 버퍼 없는 채널(보내는 쪽과 받는 쪽이 만날 때까지 대기)
- `make(chan int, 10)` — 버퍼 채널
- 보내기 `ch <- v`, 받기 `v := <-ch`, 닫기 `close(ch)`, 순회 `for v := range ch`
- `select`: 여러 채널 중 준비된 것을 처리 (타임아웃 구현에 유용)

## 동기화 도구
`sync.WaitGroup`(여러 고루틴 완료 대기), `sync.Mutex`(공유 데이터 보호), `context`(취소와 타임아웃 전파)
--- code
package main

import (
	"fmt"
	"sync"
	"time"
)

func worker(id int, jobs <-chan int, results chan<- string, wg *sync.WaitGroup) {
	defer wg.Done()
	for j := range jobs {
		time.Sleep(50 * time.Millisecond) // 작업 시뮬레이션
		results <- fmt.Sprintf("워커%d가 작업%d 처리 → %d", id, j, j*j)
	}
}

func main() {
	jobs := make(chan int, 10)
	results := make(chan string, 10)
	var wg sync.WaitGroup

	for w := 1; w <= 3; w++ { // 워커 풀
		wg.Add(1)
		go worker(w, jobs, results, &wg)
	}
	for j := 1; j <= 6; j++ {
		jobs <- j
	}
	close(jobs)

	go func() {
		wg.Wait()
		close(results)
	}()
	for r := range results {
		fmt.Println(r)
	}

	var mu sync.Mutex
	counter := 0
	var wg2 sync.WaitGroup
	for i := 0; i < 1000; i++ {
		wg2.Add(1)
		go func() {
			defer wg2.Done()
			mu.Lock()
			counter++
			mu.Unlock()
		}()
	}
	wg2.Wait()
	fmt.Println("counter:", counter) // 항상 1000

	slow := make(chan string)
	go func() { time.Sleep(2 * time.Second); slow <- "완료" }()
	select {
	case msg := <-slow:
		fmt.Println(msg)
	case <-time.After(300 * time.Millisecond):
		fmt.Println("타임아웃!")
	}
}

=== 고급 | http-server | 표준 라이브러리로 웹 서버 만들기
Go의 표준 라이브러리 `net/http` 만으로 **프로덕션급 HTTP 서버**를 만들 수 있습니다. 각 요청은 자동으로 별도 고루틴에서 처리됩니다.

## 핵심 구성
- `http.HandleFunc(패턴, 핸들러)` — Go 1.22+ 부터 `"GET /users/{id}"` 처럼 메서드와 경로 변수 지원, `r.PathValue("id")` 로 읽기
- 핸들러 시그니처: `func(w http.ResponseWriter, r *http.Request)`
- `encoding/json`: 구조체 ↔ JSON. 필드 태그 `json:"name"` 으로 키 이름 지정
- 미들웨어: 핸들러를 감싸는 함수(로깅, 인증)
- `context`: 요청 취소/타임아웃

실행 후 브라우저나 `curl localhost:8080/api/todos` 로 확인할 수 있습니다.
--- code
package main

import (
	"encoding/json"
	"log"
	"net/http"
	"strconv"
	"sync"
	"time"
)

type Todo struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
	Done  bool   `json:"done"`
}

type Store struct {
	mu     sync.Mutex
	todos  []Todo
	nextID int
}

func (s *Store) list(w http.ResponseWriter, r *http.Request) {
	s.mu.Lock()
	defer s.mu.Unlock()
	writeJSON(w, http.StatusOK, s.todos)
}

func (s *Store) create(w http.ResponseWriter, r *http.Request) {
	var t Todo
	if err := json.NewDecoder(r.Body).Decode(&t); err != nil || t.Title == "" {
		http.Error(w, "잘못된 요청", http.StatusBadRequest)
		return
	}
	s.mu.Lock()
	s.nextID++
	t.ID = s.nextID
	s.todos = append(s.todos, t)
	s.mu.Unlock()
	writeJSON(w, http.StatusCreated, t)
}

func (s *Store) get(w http.ResponseWriter, r *http.Request) {
	id, _ := strconv.Atoi(r.PathValue("id"))
	s.mu.Lock()
	defer s.mu.Unlock()
	for _, t := range s.todos {
		if t.ID == id {
			writeJSON(w, http.StatusOK, t)
			return
		}
	}
	http.NotFound(w, r)
}

func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json; charset=utf-8")
	w.WriteHeader(status)
	json.NewEncoder(w).Encode(v)
}

func logging(next http.Handler) http.Handler { // 미들웨어
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		next.ServeHTTP(w, r)
		log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(start))
	})
}

func main() {
	store := &Store{todos: []Todo{}} // 빈 목록이 null이 아닌 []로 응답되도록 초기화
	mux := http.NewServeMux()
	mux.HandleFunc("GET /api/todos", store.list)
	mux.HandleFunc("POST /api/todos", store.create)
	mux.HandleFunc("GET /api/todos/{id}", store.get)

	log.Println("http://localhost:8080 에서 실행 중")
	log.Fatal(http.ListenAndServe(":8080", logging(mux)))
}

// 테스트 (다른 터미널에서):
//   curl -X POST localhost:8080/api/todos -d '{"title":"Go 공부"}'
//   curl localhost:8080/api/todos
//   curl localhost:8080/api/todos/1

func (s *Store) remove(w http.ResponseWriter, r *http.Request) {
	id, err := strconv.Atoi(r.PathValue("id"))
	if err != nil {
		http.Error(w, "잘못된 ID", http.StatusBadRequest)
		return
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	for i, t := range s.todos {
		if t.ID == id {
			s.todos = append(s.todos[:i], s.todos[i+1:]...)
			w.WriteHeader(http.StatusNoContent)
			return
		}
	}
	http.NotFound(w, r)
}

=== 고급 | testing | 테스트, 벤치마크, 모듈 관리
Go는 테스트 도구가 언어에 내장되어 있습니다.

## 테스트
- 파일 이름: `xxx_test.go`, 함수 이름: `func TestXxx(t *testing.T)`
- `go test ./...` 로 모든 패키지 테스트, `-v` 상세 출력, `-cover` 커버리지
- **테이블 주도 테스트**: 입력과 기대값을 슬라이스로 정의하고 반복 — Go 커뮤니티의 표준 패턴
- `t.Run(이름, ...)` 으로 하위 테스트

## 벤치마크
`func BenchmarkXxx(b *testing.B)` 를 작성하고 `go test -bench=.` 로 실행합니다.

## 모듈과 도구
- `go mod init`, `go get 패키지@버전`, `go mod tidy`(불필요한 의존성 정리)
- `go vet`(의심스러운 코드 검사), `go test -race`(데이터 경쟁 탐지)
- 크로스 컴파일: `GOOS=linux GOARCH=arm64 go build` — 다른 OS용 실행 파일을 한 줄로

// mathutil/mathutil.go
package mathutil

func Reverse(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}

func IsPrime(n int) bool {
	if n < 2 {
		return false
	}
	for d := 2; d*d <= n; d++ {
		if n%d == 0 {
			return false
		}
	}
	return true
}

func TestReverse(t *testing.T) {
	tests := []struct {
		name, in, want string
	}{
		{"영문", "hello", "olleh"},
		{"한글", "안녕하세요", "요세하녕안"},
		{"빈 문자열", "", ""},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			if got := Reverse(tt.in); got != tt.want {
				t.Errorf("Reverse(%q) = %q, want %q", tt.in, got, tt.want)
			}
		})
	}
}

func TestIsPrime(t *testing.T) {
	cases := map[int]bool{1: false, 2: true, 9: false, 13: true, 97: true}
	for n, want := range cases {
		if got := IsPrime(n); got != want {
			t.Errorf("IsPrime(%d) = %v, want %v", n, got, want)
		}
	}
}

func BenchmarkIsPrime(b *testing.B) {
	for i := 0; i < b.N; i++ {
		IsPrime(1_000_003)
	}
}

--- exercise
`func Fib(n int) int` (반복문 구현)를 작성하고, `n = 0, 1, 2, 10, 20` 에 대해 기대값(0, 1, 1, 55, 6765)을 검사하는 테이블 주도 테스트 `TestFib` 를 작성하세요.
--- solution
// fib.go
package fib

func Fib(n int) int {
	a, b := 0, 1
	for i := 0; i < n; i++ {
		a, b = b, a+b
	}
	return a
}

// fib_test.go
package fib

import "testing"

func TestFib(t *testing.T) {
	tests := []struct{ n, want int }{
		{0, 0}, {1, 1}, {2, 1}, {10, 55}, {20, 6765},
	}
	for _, tt := range tests {
		if got := Fib(tt.n); got != tt.want {
			t.Errorf("Fib(%d) = %d, want %d", tt.n, got, tt.want)
		}
	}
}

? Go 테스트 파일의 이름 규칙은?
- `test_xxx.go`
+ `xxx_test.go`
- `xxx.test.go`
- `XxxTest.go`
! _test.go로 끝나는 파일은 go test 실행 시에만 컴파일됩니다.
? 데이터 경쟁(data race)을 탐지하는 명령은?
- `go vet`
+ `go test -race`
- `go fmt`
- `go mod tidy`
! -race 플래그는 실행 중 동시 접근 문제를 감지합니다.
